# Page Topology

1. Shared 68px desktop rail and 50–52px top bar — fixed/sticky platform chrome; click-driven expansion remains available.
2. Compact project header — static title, local-data boundary, one primary canvas action.
3. Workspace layout — sticky folder/filter rail plus flexible project directory.
4. Directory toolbar — click/input-driven search and sorting.
5. Project grid — click-driven new-canvas card and project links; local select controls move projects between folders.
6. Empty/error/loading states — existing truthful local states remain functional.
7. Mobile shell — no side rail in layout; compact bottom navigation and single-column project workspace.

No section is scroll-driven or time-driven. The page uses normal document scrolling with no Lenis/Locomotive behavior.
