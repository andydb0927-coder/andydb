# ProjectsWorkspace 组件规格

目标文件：`src/features/projects/ProjectsPage.tsx`、对应测试、`src/styles/global.css`。

- 来源状态：LibLib `/project` 的内部项目数据为登录态，未采集；公开可见文案只有全部项目、回收站、新建文件夹、开始创作等。本规格以本地真实功能为主。
- 页面顶部收敛为标题、真实本地项目数量、边界说明和主动作；把搜索/排序放在目录工具栏。
- 左栏是文件夹筛选与新建；右侧是 16:9 缩略图项目网格，第一张为虚线/低对比的新建卡。
- 卡片信息顺序：缩略图 → 标题/更新时间 → 节点/素材 → 创作意图 → 分类/打开。
- 移动端左栏变为横向/折行筛选区，项目网格单列；任何功能不得隐藏。
