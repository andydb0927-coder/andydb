# 页面拓扑与视觉层级

## 公开观察

- 平台采用深色背景、固定窄侧栏和轻量顶栏；主内容在桌面端从侧栏之后开始，移动端压缩为单列。
- Skill 页的核心顺序是：标题 → Agent 指令输入 → Skill/收藏/我的标签 → 分类和搜索 → 三列 Skill 卡片。卡片约 129px 高、16px 圆角、0.5px 描边、左侧封面、右侧信息和“使用”动作。
- 挑战列表是三列 16:9 媒体卡，状态徽标覆盖在封面上；移动端为单列，封面轻微缩放是主要悬停反馈。
- 挑战详情的主要内容是约 760–800px 宽的文档列；顶部有返回、标题、状态/日期和“去创作”，正文以封面、分隔线、标题、列表和提示块组成。

## 本地页面体系

```text
PlatformShell
├── 首页 /                      创作入口 + Agent + 本地作品
├── 项目 /projects              文件夹 + 工具栏 + 项目网格
├── Agent /agents              指令框 + Skill 目录 + 运行工作台
├── 挑战 /challenges           状态筛选 + 挑战卡片
│   └── 详情 /activity/:id     活动文档 + 去创作
├── 作品 /detail/:id           沉浸播放 + 互动 + 推荐
│   └── 过程 /process          只读节点 + 连线 + 复制项目
└── WorkspaceShell
    └── 画布 /project/:id      无限画布
        └── 预览 /preview      播放 + 时间线 + 导出
```

统一视觉原则：`#0b0b0d` 附近的底色、低对比表面、12–16px 圆角、1px 以下视觉描边、24–36px 页面间距、12–14px 正文、动作按钮不超过三种强调级别。功能页不使用首页式巨幅营销标题。
