# 平台功能页路由矩阵

审计日期：2026-08-23。来源只包含无需绕过权限即可看到的公开页面；账户、余额、私有项目、账单和登录后数据均不在复刻范围。

| LibLib 公开入口 | 本地路由 | 证据级别 | 融合目标 |
| --- | --- | --- | --- |
| `/` | `/` | 已观察 | 紧凑平台首页、创作入口、Agent 入口和本地作品流 |
| `/project` | `/projects` | 仅公开导航文案；内容为登录态 | 保留本地项目、文件夹、搜索、排序和移动功能，采用一致的暗色项目库 UI |
| `/skill` | `/agents` | 已观察 | Agent 指令框、分类、搜索、Skill 卡片、启停、参数和运行结果 |
| `/activity` | `/challenges` | 已观察 | 状态筛选、三列/单列挑战卡片、原创本地挑战数据 |
| `/activity/:id` | `/activity/:challengeId` | 已观察 | 活动抬头、状态/日期、文档式规则章节、去创作 |
| 作品卡片入口 | `/detail/:workId` | 入口已观察；详情模板未稳定公开 | 保留本地播放、互动、相关推荐，视觉并入平台语言 |
| 查看创作过程 | `/detail/:workId/process` | 入口已观察；内部模板未稳定公开 | 保留只读节点过程、连线显示和复制项目 |
| 画布创作 | `/project/:projectId` | 登录态，不采集内部数据 | 保留完整无限画布，只统一顶部工作区层级和状态提示 |
| 本地成片预览 | `/project/:projectId/preview` | 本地功能扩展 | 保留时间线、播放和导出，收敛为交付工作区 |
| `/cli` | `/agents#workspace-bridge` | 已观察公开安装页 | 不复制安装/账户流程；把已存在的同源工作区桥接呈现在 Agent 页内 |

不新增虚构的远程生成、云同步、社区发布、账户、积分、订阅或计费能力。页面中的数量仅来自本地仓库或明确标注的演示数据。
