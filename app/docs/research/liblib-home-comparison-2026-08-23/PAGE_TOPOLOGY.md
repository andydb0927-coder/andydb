# LibLib / Wireless Canvas 首页拓扑对比

## 观察边界

- 参考站：`https://www.liblib.tv/`，仅使用首页公开创作入口、侧栏、Agent / Skill 与 TV Show 区域；未读取或操作账号、积分、最近项目等登录态内容。
- 本地站：`http://localhost:4173/`，Mock 模式、本地持久化数据。
- 不复制 LibLib 品牌、付费、账号或远程社区能力；只复用信息层级、密度和交互模式。

## 2026-08-23 桌面证据

| 项目 | LibLib 可见界面 | Wireless Canvas 改造前 |

## 改造后的 DOM 顺序

1. 紧凑创作首屏：价值说明、新建画布、六种本地模式。
2. 产品特性横向轮播。
3. 最近项目横向列表，继续真实本地工作。
4. Agent 创意输入与 Skill 推荐。
5. TV Show 本地社区作品、分类与搜索。
6. 本地演示边界与帮助链接。

## 视觉方向

- 从长篇品牌落地页转为高频创作工作台，减少巨型标题和大段空白。
- 使用中性深灰画布和轻量暖金强调，保留 Wireless Canvas 自有身份。
- 桌面首屏控制在约 700px 内；Agent 在桌面 1100px 左右进入视野。
- 移动端保留 64px 图标侧栏，模式与项目使用横向滚动，避免近万像素长页。
