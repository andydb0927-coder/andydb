# 出海转绘工作台：交付能力边界

工作台路由`/dubbing?projectId=项目ID`；独立本地数据库`wireless-canvas-dubbing-v1`，不侵入画布Project/Asset/NodeKind，不跨浏览器自动同步。

## 三环境能力矩阵

| 能力 | 本地/静态公开版（mock构建） | 已配置开发直连/API环境 | 客户交付/外部验收环境 |
|---|---|---|---|
| 镜头、方案、返修台账 | 本地完成；最多3次返修、历史追加 | 相同本地行为 | 操作人默认local-reviewer，不等同实名客户账号 |
| 自审与交付门禁 | 运行11个自动子项；人工项目不伪装PASS | 相同规则，不因接了API放宽 | 需客户样片核验阈值、安全框、字体及例外 |
| 清单导出、刷新恢复 | JSON含版本/自审表/报告引用；IndexedDB持久化 | 相同；不自动云同步 | 不含成片、不转码、不上传、不代表签收 |
| 图片/视频/文本结果来源 | 可送入已有或上传结果；公开版不伪造真实生成 | 复用已配置provider；本批不调用任何真实API | 模型权限/余额/素材合规需另行验证 |
| 唇形精修、配音 | 无自动精修服务 | TTS需专用资源授权，Seedance依赖开通及模型能力；不承诺现有Key可完成精准口型 | 必须真实样片+人工验收，不能以文本/元数据通过代替 |
| 实际文件规格/海报/字幕样式/分轨声音 | 人工输入测量值+外部报告登记，系统不验证报告真伪 | 仍需ffprobe等外部工具，未集成自动执行 | 全片/全剧复核、商业版权确认、客户签收 |
| 飞书三栏/交付上传 | 仅规范说明，无飞书写入 | 不因配置API自动开启上传 | 内审后按甲方列规则人工上传；不得覆盖原片或意见栏 |

## 操作顺序

1. 画布/生成历史“送审到工作台”，登记原片时间码、双语台词与版本结果。
2. 配置本地化方案；待自审时填写实际检测数据，逐项修正FAIL；完成全部子项与九节排查，生成《自审确认表》并标记自审通过。
3. 打开“交付包检查与导出”，选择镜头或整集、确认全剧总集数；逐镜登记外部报告、实际交付文件引用和核验人。全部自动项须PASS，WARN也阻塞。
4. 填交付引用，生成清单并记录本地交付；在台账展开条目下载JSON。记录交付不等于文件已上传/客户签收。
5. 刷新后可重新下载历史快照。返修台账显示次数n/3、时间、操作人、基准版本和意见；满3次禁用，走人工复核，不重置记录。

完整契约：[交付硬指标与自动/外部检查边界](../../../../docs/superpowers/specs/2026-09-10-dubbing-delivery-contract.md)。

外部证据只能记载真实检测结果。对无台词/无字幕或特批规格，目前没有自动豁免通道；缺数据仍阻塞，待人工复核。不能承诺自动唇形精修、AI画面无瑕疵、版权合规认证、客户验收或自动飞书交付。
