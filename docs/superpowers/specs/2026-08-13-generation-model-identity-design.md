# 无线画布 LibTV 功能域第 5 阶段：真实生成模型身份设计规格

日期：2026-08-13

状态：已确认，进入实施

范围：在既有模型目录、Demo/LibTV 提供方切换、显式远程确认、服务端写入门禁与生成队列基础上，补齐远程模型的稳定身份绑定；不改变 LibTV CLI 命令协议、素材库、时间线或画布节点语义。

## 1. 问题与基线

当前模型中心已经可以读取 LibTV 实时目录，保存远程画布、图片模型和视频模型，并在每次远程生成前要求用户确认。目录模型同时提供 `modelKey` 与 `modelName`，但偏好、客户端请求和服务端校验只保存/比较显示名称。

单独使用名称存在三类风险：

- 同一类型目录出现两个同名模型时，选择控件无法区分，保存结果也无法证明用户选择的是哪一项；
- 模型名称与稳定键不匹配时，服务端仍可能接受被篡改或已漂移的选择；
- 生成确认只能展示名称，无法将一次确认与目录中的稳定实体对应起来。

## 2. 选定方案

远程模型选择同时固定稳定键和当前显示名称：

```ts
interface LibTvProviderSelection {
  projectUuid: string
  projectName: string
  imageModelKey: string
  imageModelName: string
  videoModelKey: string
  videoModelName: string
}
```

1. 模型选择框以 `modelKey` 作为 option value，以 `modelName` 作为用户可读文本；
2. 保存时从当前目录实体派生 key/name 对，不信任自由字符串；
3. 客户端偏好读取要求两个模型都具备完整 key/name，旧的未固定 LibTV 配置安全退回 Demo，需在模型页重新显式启用；
4. 生成请求携带完整 key/name 对；
5. 服务端必须在最新目录中找到同一条同时匹配 key 与 name 的模型，才允许调用官方 CLI；
6. CLI 仍使用当前官方命令所需的模型名称参数；稳定键仅用于身份固定和防漂移校验。

## 3. 模型中心交互

- 初始 LibTV 偏好按稳定键恢复选中项；
- 同名模型可作为两个独立 option 选择；
- 为同名项追加短键提示，避免视觉上无法区分；
- 目录刷新后，只有 key/name 对仍同时存在时启用保存；
- 目录项被删除、改名或键发生变化时禁用启用按钮，不自动改写用户偏好；
- 切回 Demo 仍需要显式保存。

## 4. 信任边界

- 浏览器 localStorage 仍是不可信输入，读取时校验 UUID 和所有非空字符串；
- 适配器在发起网络请求前重新校验完整选择；
- 服务端不因 key 存在就相信名称，也不因名称存在就忽略 key；
- 目录、错误和响应继续只保留允许字段，不渲染账户、令牌或私有模型 schema；
- `confirmed: true`、写入环境门禁、请求大小限制、素材签名验证和临时文件清理保持不变。

## 5. 兼容与迁移

- 偏好存储键保持不变，避免并存两份提供方配置；
- 已保存的 Demo 配置继续有效；
- 旧 LibTV 配置缺少稳定键时按无效配置处理并回退 Demo，不静默猜测同名模型；
- 新配置仍是可读 JSON，项目数据和 Dexie schema 不变；
- 生成结果、版本、资产和队列状态格式不变。

## 6. 可访问性与反馈

- select 保持现有明确标签“图片模型”“视频模型”；
- 同名模型的可见 option 文案附带短键，不只依赖 DOM value；
- 禁用原因保持文本可见；
- 保存成功状态继续使用 `role=status`；
- 远程确认仍显示模型名称，稳定键不作为主要视觉噪音暴露。

## 7. 验收标准

1. 同名模型可通过不同 `modelKey` 独立选择和保存。
2. 保存的 LibTV 偏好包含两个模型的 key/name 对。
3. 缺键、空键、非字符串键的持久化配置安全回退 Demo。
4. 适配器请求完整传递稳定模型身份。
5. 服务端拒绝未知键以及 key/name 错配，且拒绝发生在任何 CLI 调用和临时文件写入之前。
6. 正确固定的图片与视频生成仍把对应模型名称传给官方 CLI。
7. 既有确认、取消、重试、队列原子性和隐私边界不回归。
8. 第 5 阶段完成后路线图推进到第 6 阶段。
9. 聚焦 Vitest、全量 Vitest、typecheck、build、lint 与 diff-check 全部通过后独立提交。

## 8. 非目标

- 猜测或自动迁移未固定的旧 LibTV 模型；
- 远程任务轮询、服务端取消或费用结算；
- 修改官方 LibTV CLI 参数语义；
- 模型收藏、排序、搜索或第三方提供方接入；
- 公开部署或合并主分支。
