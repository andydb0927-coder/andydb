## 2. 实际请求合同

鉴权请求头为 `Authorization: Bearer <VITE_SEEDREAM_API_KEY>`，报告不记录密钥。两轮请求体的公共字段如下：

```json
{
  "model": "VITE_SEEDREAM_MODEL_ID（未配置时使用 doubao-seedream-5-0-260128）",
  "prompt": "清晨薄雾中的古桥",
  "size": "3136x1344",
  "response_format": "url",
  "output_format": "png",
  "watermark": false
}
```

本次没有参考图片，因此请求体不含 `image`。数量不作为火山方舟单次请求字段传递；Provider 根据 `sizePolicy.multiImageStrategy = "serial"`，数量为 2 时发送两次相同请求，并合并两次返回结果。
