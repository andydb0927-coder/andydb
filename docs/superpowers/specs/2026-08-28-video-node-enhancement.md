# 视频节点增强：规格与 TDD 验收

起点：`b9fab4d`，分支 `codex/platform-shell-phase`。仅 fixture 测试；不读取密钥、不调用真实生成、不清理用户数据。保留在途三张 QA 截图。

## 官方能力复核（2026-08-28）

来源：[创建任务](https://www.volcengine.com/docs/82379/1520757)、[查询任务](https://www.volcengine.com/docs/82379/1521309)。通过内置浏览器读取官方字段正文及首尾帧请求示例。

- Seedance 2.0 支持首帧和首尾帧。`content[]` 的图片使用 `type:image_url`，`role:first_frame/last_frame`。首帧 1 张，首尾帧 2 张；两张可相同。首尾图比例不同时官方以首帧为准并裁剪尾帧。
- 首帧、首尾帧、全模态参考是互斥场景。不能额外混入参考图、视频或音频。旧数据按原图片顺序兼容；新 UI 明确选帧，不能静默丢帧或错置角色。
- 当前创建字段无独立 `negative_prompt`、景别、运镜结构化字段。本批将它们声明为**提示词引导**，在适配器内拼接，不伪造 API 参数；没有承诺严格负面约束效果。
- 查询返回 `duration/resolution/ratio/framespersecond/usage`；保留真实返回元信息。像素尺寸从媒体元数据读取，缺失帧率或费用标未提供，不用示例值替代。
- 官方限制：单参考图宽高 300–6000，比例 0.4–2.5，小于 30MB；真人参考仍受官方授权/风控约束。本批不绕过供应商限制。

## 交互与数据决策

1. 生成参数按 manifest 呈现负面词、景别、运镜；仅声明支持的模型显示。图生视频显示首帧选择，首尾帧显示两项；来源当前项目图片资产。选择结果写入 generationConfig 的可选 role 字段，兼容旧数据。
2. 结果播放器旁显示实际时长、尺寸/分辨率、FPS、该版本费用。版本历史只列有视频资产的版本，可恢复视频、提示词、模型与生成配置；不发起生成、不删除历史，一次撤销可恢复。生成中不允许切版本。
3. 本地工具复用 Canvas + MediaRecorder：截取/裁剪/水平与垂直镜像/90度旋转/0.25–4倍速/画中画/三分屏。组合源选当前项目视频，短副片循环，按主片选区时长输出；保留原节点，导出新资产和视频节点。画面合成暂只输出视频画面，明确提示不含音轨。浏览器不支持、跨域或解码失败给错误，不伪报完成。
4. 处理期间防重复提交；项目/画布切换或卸载取消处理，避免回填错项目。所有新增字段可选，旧项目不迁移、不清库。
5. 本地编辑器、截取与裁剪共用真实元数据读取。MediaRecorder 产生的 WebM 可能没有时长头，先解码末尾再回到起点；失败时显示原因并禁用导出，不以旧资产时长或默认 3 秒代替。缩略条读取同一素材的 12 个真实抽帧。
6. 视频版本条位于独立 composer 内，避免挤占固定媒体框及遮挡播放器；小视口合成弹窗采用固定头尾、内容滚动，导出与取消始终可达。

## TDD 与门禁

- 先红：首尾帧乱序/缺帧/互斥、manifest与提示词映射、元信息；本地变换尺寸/时长/布局/非法范围；版本恢复幂等/撤销/持久化。
- 再绿：组件测试涵盖字段与禁用原因、结果信息和历史切换、合成表单；E2E fixture 验证首尾帧请求/真实本地处理产物/刷新恢复。
- 门禁顺序：typecheck → Vitest → build:mock → 全量 Playwright（独立端口、新上下文、外网拦截）。记录实际结果，恢复被测试覆盖的原截图；凭据扫描、diff 检查后提交推送。
