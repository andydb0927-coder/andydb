# 无线画布连线显示/隐藏设计规格

日期：2026-08-11  
状态：待书面复核  
范围：项目画布中的连线可见性控制

## 1. 目标

为画布增加 LibTV 风格的全局连线显示/隐藏控制，让用户在节点关系复杂时获得更干净的工作区，同时不破坏建立新连线的能力。

本轮只改变当前画布的视觉呈现，不改变项目关系数据、撤销历史、保存状态或时间线。

## 2. 已确认的产品决策

1. 连线可见性是画布局部视图状态，默认显示。
2. 隐藏只影响连线曲线、方向箭头和边的命中区域。
3. 节点端口在悬停、聚焦、选中和连线模式下仍可出现。
4. 隐藏状态下仍可使用 `L` 进入连线模式并建立新连接。
5. 显示/隐藏不写入 `Project`、Zustand Store、Dexie 或撤销历史。
6. 刷新页面后恢复默认的“显示连线”状态。
7. 本轮不支持单条边独立隐藏。

## 3. 交互设计

### 3.1 工具栏控制

- 在现有画布工具栏中，紧邻“连线”工具增加独立的可见性按钮。
- 连线可见时，按钮名称为“隐藏连线”，使用 `EyeOff` 图标。
- 连线隐藏时，按钮名称为“显示连线”，使用 `Eye` 图标。
- 按钮使用 `aria-pressed` 表达当前状态，并支持鼠标、Enter 和 Space。
- 切换到隐藏时清除当前边选中状态，避免出现看不见的删除操作。
- 切换回显示时恢复所有已有连线的曲线、箭头和可选中区域。

### 3.2 快捷键

- 使用 `H` 在显示和隐藏之间切换。
- 快捷键只在画布处于普通浏览状态时生效。
- 输入框、文本域、下拉框、`contenteditable`、弹窗和带修饰键的按键事件不触发切换。
- 快捷键不抢夺当前焦点，也不改变当前工具；如果“连线”工具已激活，仍保持激活。

### 3.3 隐藏状态反馈

- 切换完成后通过现有状态反馈区域报告“连线已隐藏，端口仍可使用”或“连线已显示”。
- 反馈使用 `aria-live="polite"`，不阻塞用户继续操作。
- 不增加常驻侧栏或大面积提示，保持 LibTV 风格的紧凑画布。

### 3.4 窄视口

- 721×778 等窄视口下，按钮仍在工具栏可见、可聚焦和可点击。
- 按钮不得覆盖 AI 导演输入框、节点主操作或连接状态提示。
- 图标按钮提供稳定的可访问名称和悬浮提示，不依赖图标形状传达状态。

## 4. 状态与组件边界

### 4.1 CanvasPage

`CanvasPage` 持有 `connectionsVisible: boolean` 局部状态，初始值为 `true`。

- 切换函数只更新局部状态，并在隐藏时清除 `selectedEdgeId`。
- 现有 `project.edges` 仍是唯一正式关系数据源。
- 现有 `connectNodes`、`disconnectNodes`、撤销/重做、自动保存和加载流程不变。
- 页面卸载、项目切换和刷新都让视图状态回到默认显示。

### 4.2 CanvasToolbar

工具栏接收可见性状态和切换回调，渲染一个独立按钮。该按钮不属于 `CanvasTool` 类型，不会触发工具切换，也不会影响“选择”“连线”等工具的 `aria-pressed` 状态。

### 4.3 DependencyEdge

边渲染器接收 `visible` 视图参数：

- `visible=true`：渲染现有曲线、方向箭头、交互命中层和选中删除操作。
- `visible=false`：不渲染曲线、箭头、交互命中层和边删除操作。
- 边对象仍保留在 `project.edges` 中；重新显示后不重新生成 ID、不改变来源变更状态。

隐藏时不保留边的焦点或选中状态，避免键盘操作落在不可见元素上。

## 5. 关键行为流程

### 5.1 隐藏与显示

1. 用户点击“隐藏连线”或按 `H`。
2. `CanvasPage` 将 `connectionsVisible` 设为 `false`，清除边选中状态。
3. React Flow 边层移除曲线、箭头和边命中元素。
4. 状态区域播报“连线已隐藏，端口仍可使用”。
5. 用户点击“显示连线”或再次按 `H`。
6. 边层恢复全部连线渲染，状态区域播报“连线已显示”。

### 5.2 隐藏状态下新建连线

1. 用户按 `L` 或点击“连线”。
2. 节点端口按现有规则显示并支持键盘/鼠标选择。
3. 用户完成合法连接后，Store 写入新的边。
4. 新边在隐藏状态下仍不显示；用户切回显示后可以看到它。
5. 连接失败、取消、撤销和重做沿用现有行为。

## 6. 错误与边界处理

- 快捷键输入不应在文本节点编辑、AI 导演输入、表单控件或弹窗内改变可见性。
- 隐藏时若存在旧的 `selectedEdgeId`，必须在同一次切换中清除，不产生历史记录。
- 项目切换或加载失败时，局部状态重置为显示，不向项目写入任何视图偏好。
- 连接创建失败不改变可见性状态，也不覆盖现有连接错误反馈。
- 连线隐藏不改变节点位置、节点选中、生成任务、时间线或预览路由。

## 7. 测试与验收

### 7.1 组件测试

- 默认渲染“隐藏连线”按钮并表示可见状态。
- 点击、Enter、Space 都能切换按钮名称与 `aria-pressed`。
- 隐藏时传给边渲染器的 `visible` 为 `false`，并清除选中边；显示时恢复为 `true`。
- `H` 在画布普通状态下切换；输入框、文本域、下拉框、`contenteditable`、弹窗和修饰键事件不切换。
- 切换不调用 Store mutation、持久化或历史 API。

### 7.2 真实 Chromium 测试

- 在已有依赖边的真实画布中点击隐藏，确认曲线、箭头和边命中层消失。
- 点击显示，确认同一组边恢复，边 ID、方向和标签保持一致。
- 隐藏后通过 `L` 与真实端口创建新边，并在显示后确认新边出现。
- 使用键盘 `H`、Enter、Space 完成切换，确认焦点和工具状态稳定。
- 在 721×778 视口中确认按钮矩形完整可见、中心命中按钮、无控制台错误。
- 刷新后确认默认恢复显示，且项目边数据保持不变。

### 7.3 全量门禁

- Vitest 全量测试通过。
- TypeScript 类型检查通过。
- Oxlint 无新增错误。
- 生产构建通过。
- Chromium 全量端到端测试通过。
- `git diff --check` 通过。

## 8. 非目标

本轮不实现：

- 将可见性偏好保存到项目或跨设备同步。
- 单条边隐藏、按节点类型过滤或按分组过滤。
- 自动布局、小地图、时间线、导出、生成队列或模型接入改造。
- 新增全局侧栏、关系编辑器或协作权限。

## 9. 完成标准

1. 用户能通过按钮和 `H` 在显示/隐藏之间稳定切换。
2. 隐藏只影响曲线、箭头和边命中层，端口连线能力保持可用。
3. 项目关系、保存状态、撤销历史、生成任务和时间线完全不变。
4. 普通视口和 721×778 窄视口下交互均可达。
5. 单元、组件、类型、构建和 Chromium 全量门禁通过。
