# 无线画布 LibTV 功能域第 13 阶段：Agent、Skill 与 CLI 运行设计规格

日期：2026-08-13

状态：已确认，进入实施

## 1. 基线与缺口

现有系统已覆盖五个本地确定性技能、插件注册、输入 schema 校验、启停偏好、结果卡与画布节点写入；server 已有四个版本化 workspace 命令、统一 envelope、1 MiB 输入上限和 Vite 白名单中间件。

本阶段需补齐：可取消执行、跨技能重复执行保护、过期结果隔离、结果输出契约校验、重复写入保护，以及平台页对 CLI 桥接状态的真实展示。

## 2. Skill 执行生命周期

- `AgentSkillContext` 接收可选 `AbortSignal`；注册表在执行前和输出后都检查取消状态；
- 取消使用稳定 `SKILL_EXECUTION_CANCELLED` 错误，已取消结果不得进入 UI；
- 同一时刻最多一个技能运行，运行期间禁用其他运行入口；
- 切换项目时取消当前运行并清理上一项目结果；
- 技能输出必须具有非空标题、摘要、正文与受支持格式，否则返回 `SKILL_OUTPUT_INVALID`。

## 3. 结果写入安全

- 结果绑定执行时的项目 ID，不能写入后来切换的项目；
- 写入期间禁用按钮，成功后显示“已写入画布”并阻止重复保存；
- 写入继续通过 `ProjectRepository.save`，不绕过本地持久化边界。

## 4. CLI 桥接状态

- 新增浏览器端 `WorkspaceManifestClient`，只读取同源 `/api/workspace/manifest`；
- 严格校验 HTTP 状态、envelope 版本、namespace 和命令摘要字段；
- `/agents` 显示“已连接”与命令列表，或明确“当前构建未启用本地 CLI 桥接”；
- 失败文案固定，不显示网络、路径或内部错误详情；
- 不执行命令、不读取 IndexedDB、不向外部网络发送数据。

## 5. 验收标准

1. 未知技能、输入错误、输出错误和取消错误均稳定。
2. 运行期间不能并发启动第二技能，取消后不显示过期结果。
3. 结果只能写入一次且只能写入原项目。
4. CLI manifest 合法时显示命令，不可用或结构错误时诚实降级。
5. 第 13 阶段完成后路线图 13/13 完成。
6. 聚焦/全量 Vitest、typecheck、build、Oxlint 和 diff-check 通过后独立提交。
