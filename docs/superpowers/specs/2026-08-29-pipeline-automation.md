起点 `458f7ced18f993ad6f0f288501d5514e21cb1f05`，分支 `codex/platform-shell-phase`。保留已有三张用户截图。基线：189 文件 / 1556 单测 / 121 E2E。

## 执行契约

- 从选中的脚本、文本或图片起点，沿出边取可达子图；复用整组执行的拓扑校验，拒绝循环与悬空边。不影响原整组执行入口。
- 步骤使用统一 `TaskStatus`；管线另有暂停原因与跳过标记，避免把暂停冒充失败。每步重新读取上游最新文本与媒体，走现有注册表与 `GenerationQueue`，不静默回退 Demo。
- 支持生成、使用现有结果、图片本地后处理（镜像/旋转）三类步骤；后处理读上游真实图片并生成新资产。已有注册表编辑/续写/分析配置继续走对应 provider。未接入的工具给出明确原因，不伪造结果。
- 执行前展示节点数与预计积分；自动重试计入最高预算。只授权本次管线，执行中禁止新增并行管线。测试一律 fixture 拦截、不调用真实 API。
- 暂停在当前步骤完成后生效；取消中止当前步骤，保留已完成；失败默认暂停，可重试或跳过。继续策略保留失败，跳过依赖失败的分支、执行独立分支；重试上游后重新开放因依赖失败而跳过的节点。
- 刷新/切项目/切画布停止本地调度，不自动重发。已完成结果保留；恢复记录与已持久任务对账，显式继续后才执行未完成项。取消并不保证已提交第三方任务免单。
- 保存失败独立于供应商失败：一律暂停，不消耗自动生成重试预算；若任务已成功而项目未落盘，手动重试仅补保存，不再次生成。

## 数据与界面

- IndexedDB 追加 `pipelineRuns`、`pipelineTemplates`，不改旧数据结构、不清库。运行保存起点/画布/拓扑/步骤/次数/失败策略/开始结束时间；历史按项目与画布隔离。
- 模板保存节点类型、输入提示词、参数、位置、拓扑和步骤动作；移除生成结果、版本、历史、媒体 URL 与资产/主体引用。跨项目实例化重新生成所有节点与边 ID，缺少素材需重新选择。
- 画布顶栏「管线自动化」图标（悬浮提示与可访问名称）与起点右键「执行下游管线」。执行面板含准备/运行/模板/历史，单步状态、跳过/重试、暂停/取消、整体进度；节点徽标同步运行状态。对话框支持 Escape、焦点回归、窄视口滚动，保持既有 56px 顶栏与画布可用空间。
