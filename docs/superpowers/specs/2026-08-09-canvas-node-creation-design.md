# 画布节点创建设计规格

日期：2026-08-09
状态：已批准，待实施计划
适用项目：无线画布 V1

## 1. 目标

让左侧工具栏中的“文本、图片、分镜、视频”从视觉入口变为可完成的节点创建流程。用户先选择工具，再点击画布空白处决定节点位置，通过落点附近的轻量创建面板补充内容，确认后获得一个可撤销、可保存、可刷新恢复的真实节点。

本轮不实现连线工具模式、分组容器、复杂素材库、批量导入、拖拽上传或新的侧边栏和路由。

## 2. 已批准的交互方案

1. 用户点击“文本、图片、分镜、视频”之一。
2. 对应工具进入按下状态，画布进入放置模式并显示明确的放置提示。
3. 用户点击画布空白处。
4. 系统同时记录：
   - 经 React Flow 转换后的画布坐标，用作节点位置；
   - 当前视口内的屏幕坐标，用作轻量面板锚点。
5. 落点附近打开轻量创建面板；面板自动避开视口边缘。
6. 用户确认后，节点和可选素材通过一次原子项目变更写入，节点自动选中，工具恢复为“选择”。
7. 用户取消或按 `Esc` 时不修改项目、不产生撤销记录，工具恢复为“选择”。

创建面板打开期间不接受第二个画布落点。完成一次创建后不保持连续创建模式，避免误触产生重复节点。

## 3. 节点类型与字段

### 3.1 文本节点

- 默认标题：`文本 NN`。
- 必填字段：标题、文字内容。
- 文字内容写入初始版本的 `prompt`。
- 节点可参与连线，并可使用“生成分镜”操作创建下游分镜。

### 3.2 图片节点

- 默认标题：`图片 NN`。
- 必填字段：标题、本地图片。
- 可选字段：图片描述。
- 支持 PNG、JPEG、WebP，原文件不超过 8 MB。
- 图片读取为项目内持久化的数据 URL，并创建一条 `image` Asset；初始版本引用该 Asset。
- 图片描述为空时，初始版本的 `prompt` 使用节点标题，保证版本内容非空。
- 节点可参与连线，并可使用“生成视频”操作。

### 3.3 分镜节点

- 默认标题：`分镜 NN`。
- 必填字段：标题、画面提示词。
- 提示词写入初始版本；创建时不要求已有图片素材。
- 沿用重生成、扩展镜头和生成视频操作。

### 3.4 视频节点

- 默认标题：`视频 NN`。
- 必填字段：标题、视频提示词。
- 提示词写入初始版本；创建时不要求已有视频素材。
- 没有可播放素材时不能加入时间线；生成成功后沿用加入时间线操作。

标题去除首尾空白后长度为 1–40 个字符。文本内容或提示词去除首尾空白后长度为 1–1000 个字符。默认编号取同类型现有默认编号中的最大数字再加一，并补足两位；没有可识别编号时从 `01` 开始。用户可以修改标题，也允许主动使用重复标题。

## 4. 组件与职责边界

### CanvasToolbar

- 改为受控组件。
- 接收当前工具、工具变更回调和创建面板打开状态。
- 负责按钮的 `aria-pressed`、可见选中状态、提示文案和焦点引用。
- 不负责坐标转换、表单或项目写入。

### CanvasPage

- 保存当前工具和未提交草稿锚点。
- 只响应 React Flow 的空白画布点击；节点、连线、上下文操作、工具栏和 AI 导演点击不会触发创建。
- 使用 React Flow `screenToFlowPosition` 计算节点位置，保证缩放和平移后的落点正确。
- 控制创建面板的打开、取消、提交、项目切换清理和创建后节点选择。
- 不在组件内读取图片文件或拼装完整项目变更。

### NodeDraftPanel

- 独立管理标题、内容、文件和行内错误。
- 根据节点类型渲染对应字段。
- 负责文件类型、文件大小和文本长度校验。
- 图片读取成功后才提交结构化草稿；失败时不触发项目变更。
- 宽度不超过 320 CSS px，并在 200% 浏览器缩放下限制在可见视口内。

### 节点工厂

- 接收已校验草稿、画布坐标和当前项目。
- 生成节点、初始版本和可选 Asset 的稳定结构。
- 生成唯一 ID、时间戳和默认编号。
- 不访问 React、DOM、文件输入或项目仓库。

### Project Store

- 新增原子创建操作，输入一个节点和可选 Asset。
- 在一次 `commit` 中同时写入 Asset 与节点，形成一条历史记录并将保存状态置为 `dirty`。
- 撤销同时移除节点和本次创建的 Asset；重做同时恢复二者。
- 沿用现有串行自动保存和 Dexie 持久化，不新增独立保存通道。

## 5. 数据模型

- `NodeKind` 增加 `text` 与 `image`。
- `text` 和 `image` 注册到现有 React Flow `nodeTypes`；两者复用创作节点壳层，仅替换类型图标和兼容操作。
- 所有新节点创建时都包含一个初始版本和有效的 `activeVersionId`。
- 图片 Asset 与节点在同一项目快照内持久化；不使用仅当前页面有效的 `blob:` URL。
- 新建图片若被撤销，其本次新增 Asset 随同节点撤销，不遗留孤立素材。

## 6. 键盘、焦点与可访问性

- 工具按钮通过鼠标或键盘激活，并正确暴露 `aria-pressed`。
- 面板打开时焦点进入第一个可编辑字段。
- 标题输入框中的 `Enter` 不作为全局快捷键；多行内容中的普通 `Enter` 始终换行。
- `Command/Ctrl + Enter` 在表单有效时提交。
- `Esc` 取消并将焦点还给启动创建流程的工具按钮。
- 创建成功后焦点移动到新节点的选择表面，读屏用户能立即听到节点标题与类型。
- 所有错误使用文字提示并与字段建立可访问关联，不只依赖颜色。
- 在 200% 浏览器缩放下，面板全部字段、错误信息、取消和确认按钮均保持可见、可聚焦、可点击。

## 7. 异常处理

- 非空白画布点击：忽略，不打开面板。
- 缺少标题或必填内容：显示行内错误，不修改项目。
- 图片类型不支持或超过 8 MB：显示明确错误，不读取或保存文件。
- 图片读取失败：保留用户已填写的标题和描述，允许重新选择文件。
- 项目路由切换或组件卸载：丢弃未提交草稿，不写入旧项目。
- 自动保存失败：节点仍保留在本地项目状态，继续使用现有顶部保存错误提示和后续重试机制。
- 提交期间重复点击：确认按钮禁用，保证一次操作只创建一个节点。

## 8. 测试策略

### 单元测试

- 节点工厂为四种节点生成正确类型、默认标题、初始版本和坐标。
- 图片输入生成 Asset 引用；无图片或不合规图片不能生成提交结果。
- Store 原子写入节点与 Asset，只产生一条历史；撤销和重做恢复一致快照。
- 新类型渲染正确图标、类型文案和兼容操作。

### Canvas 集成测试

- 选择工具后按下状态正确；节点和操作点击不会误触创建。
- 空白画布点击使用转换后的画布坐标打开面板。
- 取消、`Esc`、项目切换不会产生项目变更。
- 确认后节点创建、自动选中、工具复位并触发一次保存。
- 图片错误保留表单，成功提交后刷新仍显示图片。
- 200% 布局下创建面板保持在视口内。

### 端到端测试

- 依次创建文本、图片、分镜和视频节点。
- 拖动新节点，撤销、重做并刷新页面，确认节点位置、内容和图片素材保持一致。
- 使用键盘完成工具激活、面板填写、提交和取消。
- 检查浏览器控制台无错误，并保留现有生成、预览、导出和缩放验收流程。

## 9. 验收标准

1. 四种创建工具均能在用户点击的画布位置生成真实节点。
2. 创建确认前项目保持不变；确认后只产生一条可撤销历史。
3. 新节点自动选中并可继续拖动、连线或执行兼容操作。
4. 图片节点刷新后仍显示原图，且没有孤立 Asset。
5. 自动保存、撤销、重做和真实 Dexie 恢复保持一致。
6. 鼠标、键盘和 200% 浏览器缩放流程均可完成。
7. 现有生成、时间线、预览、导出和节点拖动测试继续通过。

## 10. 非目标

- 连线工具专用模式与分组容器。
- 拖拽文件到画布、批量图片导入和素材库管理。
- 节点内联编辑、富文本编辑器和提示词高级参数。
- 云端文件上传、真实视频文件导入和媒体转码。
- 连续创建模式、自动布局和对齐吸附。
