## 3. 高级设置与个性化风格 P 值

点击滑杆图标后，高级设置由高度 `0` 展开为完整参数区。实际字段如下：

| 字段 | 当前节点值 | Schema 默认 | 范围/步长 | 官方提示 |
| --- | ---: | ---: | --- | --- |
| 个性化风格 P 值 | 空字符串 | 空字符串 | 文本输入 | “同步你的 MJ 专属风格；在 Midjourney 中找到 P 值，复制并粘贴到右侧输入框” |
| 风格化程度 | **150** | **100** | 0–1000，步长 50 | 控制画面艺术化程度，越高越具创意 |
| 怪异度 | 50 | 50 | 0–3000，步长 50 | 控制画面非常规程度，越高越脑洞大 |
| 多样性 | 5 | 5 | 0–100，步长 5 | 控制生成差异度，越高结果越随机 |
| 智能引用 AutoLink | 开启 | 非模型 Schema 字段 | 开关 | 自动解析 prompt 内的节点/资源引用 |

重要区别：页面当前“风格化程度”是 150，而模型 Schema 默认值是 100，说明该节点保存了用户历史参数，不能在复刻时用模型默认值覆盖既有节点值。

可访问性观察：三个滑杆虽然有 `role=slider` 和 min/max/now，但 `aria-label` 为空；视觉标签与滑杆没有形成明确的程序化名称。

## 4. “参考”入口

点击“参考”后不是普通资产弹窗，而是进入画布内引用选择模式：

1. 顶层提示变为“从画布选择参考”；
2. 出现“返回节点”按钮；
3. 出现“退出”按钮；
4. Tooltip 为“在当前画布中添加参考”；
5. 用户应在当前画布点击其他图片/媒体节点，建立当前生成节点对该节点的引用；
6. 本次没有选择任何参考，直接点击“退出”，因此未新增入边或媒体参数。

设计含义：参考入口优先复用画布中的既有节点，而不是强制再次上传；引用完成后应落为入边和/或 prompt 中的节点引用。

## 15. 直接动作、配置动作和消耗动作分类

| 类别 | 操作 | 安全语义 |
| --- | --- | --- |
| 只读展开 | 高级设置、风格库、参考选择模式、九宫格菜单、宫格切分菜单、多结果、预览 | 关闭后不应改变项目 |
| 草稿编辑器 | 多角度、打光、标注 | 只有点击生成/保存后才应写新结果；Escape 应无副作用 |
| 点击即插入节点 | 人像调节、全景、高清 | 点击入口即写 Store 和连线，虽未生成也属于项目变更 |
| 直接修改/文件动作 | 设为主图、旋转、下载 | 分别改变节点输出、改变图片角度或写入本地文件 |
| 明确消耗动作 | 节点生成箭头、多角度/打光提交、九宫格模板执行等 | 必须在成本可见且用户明确提交后进入任务队列 |

当前体验问题：人像调节、全景、高清看起来与普通“打开工具”按钮一致，但点击即插入节点，缺少“将添加工具节点”的预反馈。这对只读检查和误触防护不友好。

## 17. 结论

该图片节点不是“图片 + prompt”的简单卡片，而是四层组合：

1. 多候选结果及主图选择；
2. 模型驱动的 prompt、比例、质量、数量和高级参数；
3. 画布引用、风格模板与 AutoLink；
4. 面向现有图片的派生工具，包括多角度、打光、九宫格、高清、全景、标注等。

其中最需要在复刻时区分的是：**弹窗式草稿编辑器**、**点击即插入工具节点**、**直接修改当前结果**和**真正生成扣费**四种操作。它们目前视觉样式接近，但副作用完全不同，应通过文案、可访问名称、成本提示和撤销反馈明确分级。
