# 无线画布首页改版规格：LibTV 型本地创作门户

日期：2026-08-13  
状态：已确认，直接执行  
范围：仅改造 `/` 首页及首页态导航；不重写已有项目、画布、作品详情或创作过程页面。

## 1. 公开页面依据与证据边界

2026-08-13 对 `https://www.liblib.tv/` 公开首页做只读核对，公开可见结构包括：

- 侧边导航：首页、项目、Skills、创作者挑战赛、帮助；
- Hero 标题“只需一张画布 连接你的多种创意想法”、主创建按钮与 6 个创作入口；
- Seedance 2.5、导演台、Blender 插件、Minimax H3 等产品特性入口；
- LibTV Agent 创意输入和专业影视、商业广告、音乐 MV 分类；
- TV Show 分类、搜索和作品列表。

未登录公开页的 Skill 分类显示为 0 个，因此本实现不推断官网登录态数据，也不调用 LibTV、模型、积分、会员或任何外部 API。Skill、作品、播放量、作者和产品特性全部使用本地固定演示数据。

## 2. 当前应用基线

首页已经组合项目创建器、本地首页种子和社区作品；现有能力必须继续可用：

- `/` 的配方创建、空白项目、最近项目与失败重试；
- `/projects` 项目空间与 IndexedDB 项目数据；
- `/project/:projectId` 画布和 `/project/:projectId/preview` 预览；
- `/discover/:workId` 作品详情及“查看创作过程”；
- `/models`、`/workflows`、`/agents`、`/account` 等平台页；
- 现有画布节点、连线、生成桥、素材、时间线、导出、持久化与键盘行为。

本阶段不修改上述数据模型和核心路由。首页入口只能链接到现有真实页面或触发已有的本地项目创建流程。

## 3. 首页信息架构

### 3.1 首页态平台导航

- 顶栏右侧依次提供“积分超市”“开通会员”“注册/登录”，均进入现有 `/account` 的对应锚点或页面，不伪造支付与登录成功。
- 首页侧栏依次提供：首页、项目、Skills、创作者挑战赛、帮助；另保留可验证的“新建项目”锚点入口。
- 只在 `/` 使用精简首页侧栏。进入其他平台功能页后仍显示原完整功能导航，防止素材、故事、工作流、剪辑、交付、模型等既有入口消失。
- 工作区模式及阶段任务抽屉保持原行为。

### 3.2 Hero 与六个创作入口

- 标题固定为“只需一张画布 连接你的多种创意想法”。
- “新建画布创作”定位到保留的项目创建器。
- 六个本地入口固定为：SD2.5直出5分钟视频、片段重拍、智能引用 AutoLink、讲解视频、素材混剪、逐帧拉片。
- 点击入口复用现有保存、hydrate、进入画布流程，并把对应模式提示写入项目意图。

### 3.3 产品特性轮播

- 展示 5 张本地卡片，至少覆盖模型上新、导演台和插件。
- 每张卡指向已存在的 `/models`、`/agents` 或 `/workflows`。
- 提供上一张、下一张和当前位置状态；键盘可聚焦，切换不自动播放。
- 页面加载时第一张为当前特性，循环切换 5 张卡。

### 3.4 Agent 与 Skill

- 创意输入为空时显示可访问错误；输入后发送会创建“创意草稿”本地项目并进入画布。
- 保留本地附件文件名反馈，不读取、上传或发送文件内容。
- Skill 分类横排展示：专业影视、商业广告、音乐MV；每类含两张本地 Skill 卡。
- 卡片包含封面、名称、描述、作者、使用数和“使用 Skill”按钮；点击按钮复用项目创建流程。

### 3.5 TV Show

- 分类：全部、Seedance2.5、精选画布、专业影视、短剧漫剧、商业广告、动漫游戏、教育生活。
- 搜索框和搜索按钮只过滤本地作品的标题、作者和标签。
- 瀑布流作品卡保留视频封面、浏览/播放数、作者、认证徽章、标题及“查看创作过程”。
- 作品封面和创作过程按钮继续进入现有 `/discover/:workId`；作者链接继续进入创作者主页。

### 3.6 保留区

- 现有项目创建表单与最近项目列表继续位于首页后半段，确保原入口和数据不丢失。
- 帮助锚点明确说明本地演示边界，并提供项目、Skills、作品墙的真实内部链接。

## 4. 视觉与响应式方向

- 使用深色电影工作台视觉、紫蓝高光、低饱和卡片与大留白，形成“创作门户”而非后台表格。
- Hero 在宽屏形成左右层次，六入口为三列；产品特性卡片保留前后卡片的空间提示。
- Skill 分类为横向胶囊，TV Show 使用响应式瀑布列；窄屏回退到单列，不产生横向页面滚动。
- 所有图像使用已有 `/demo/*` 本地素材；不新增远程图片依赖。
- 尊重 `prefers-reduced-motion`，轮播不自动播放，悬停效果不承担唯一信息表达。

## 5. 状态、可访问性与失败边界

- 首页内容和社区数据各自有 loading/error 状态；任何一个失败都不阻断项目创建器。
- 轮播状态使用 `aria-live=polite`；分类使用 `aria-pressed`；搜索使用原生 `form` 和 `search` 输入。
- 所有图标为装饰或具有稳定中文可访问名称；按钮和链接支持键盘操作与可见焦点。
- 顶栏的积分、会员和登录只导航到本地账号页，不显示虚假的购买、开通或登录结果。

## 6. 非目标

- 不复刻 LibTV 品牌资产、文案以外的版权图片或登录态私有内容。
- 不新增真实生成、真实积分、支付、登录、远程 Skill 安装或外部发布。
- 不改造 `/discover`、`/models`、`/agents` 等功能页本体。
- 不删除或隐藏非首页页面上的现有完整平台导航。

## 7. 验收标准

自动化测试必须证明：

1. 首页态侧栏和顶栏具有指定入口，其他平台页仍保留完整导航。
2. Hero 精确文案、主按钮和 6 个模式存在，模式点击仍创建并持久化项目。
3. 特性轮播恰有 5 张内部链接卡，前后切换和状态正确。
4. Agent 创意发送、附件反馈与三类 Skill 切换/使用正确。
5. TV Show 含 8 个分类、搜索按钮、本地过滤和作品详情/创作过程链接。
6. 原项目创建、最近项目、作品详情和既有路由测试保持通过。
7. focused Vitest、全量 Vitest、typecheck、build、`git diff --check` 全部通过后才允许提交。
