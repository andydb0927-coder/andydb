# 无线画布 LibTV 功能域第 6 阶段：素材历史与安全生命周期设计规格

日期：2026-08-13

状态：已确认，进入实施

范围：在既有本地素材上传、SHA-256 去重、搜索筛选、跨项目复用、项目素材快照和任务记录基础上，补齐完整节点版本历史与未引用素材的安全删除；不改变画布生成、时间线剪辑或远程存储。

## 1. 问题与基线

当前“素材与历史”页已经提供：

- 图片、视频、音频本地上传与 20 MiB 限制；
- 文件字节 SHA-256 去重和并发导入去重；
- 素材来源、时间、大小、尺寸、类型、搜索和筛选；
- 把图片/视频素材原子保存到目标项目后打开画布；
- 项目资产快照、当前节点版本、生成任务和导出任务记录。

但页面只读取每个节点的 `activeVersionId`，历史版本完全不可见；素材目录也没有删除入口。直接增加无保护删除会破坏项目引用和版本可追溯性，因此必须先建立跨项目引用检查。

## 2. 选定方案

### 2.1 完整版本历史

- 每个节点展示全部版本，而非只展示当前版本；
- 版本按创建时间从新到旧排列，时间相同则保持项目内稳定顺序；
- 当前版本显示明确“当前”标记，其他版本显示“历史”；
- 展示版本提示词、创建时间、关联素材名称或 ID、关联生成任务；
- 每个节点保留“在画布中查看”链接并聚焦来源节点；
- 本阶段只读浏览，不在历史页切换活动版本，避免绕过画布撤销和依赖变更语义。

### 2.2 安全删除

- 素材卡提供“删除素材”操作；
- 点击后打开模态确认，初始焦点在取消按钮，Escape 取消并将焦点还给触发按钮；
- 确认后由仓库在单个 Dexie 读写事务内重新检查所有项目引用；
- 引用范围覆盖项目 assets、节点版本、生成/导出任务和结构化创作卡图片；
- 只在没有任何项目引用时删除素材目录记录；
- 有引用时返回引用项目数量，保持目录记录和项目数据不变；
- 素材在确认前已不存在时按幂等完成处理，不显示伪失败。

## 3. 仓库契约

```ts
type DeleteLibraryAssetResult =
  | { status: 'deleted' }
  | { status: 'missing' }
  | { status: 'referenced'; projectIds: string[] }

deleteUnreferenced(assetId: string): Promise<DeleteLibraryAssetResult>
```

- 事务同时锁定 `projects` 与 `libraryAssets`；
- 项目引用检查和删除之间不可被项目保存穿插；
- `projectIds` 去重并保持数据库读取顺序；
- 不删除项目、节点、版本、任务或时间线；
- 不级联删除文件系统或远程 URL。

## 4. 页面状态与错误恢复

- 删除成功或素材已不存在：从当前目录视图移除卡片并用 `role=status` 反馈；
- 仍被引用：关闭确认框，以 `role=alert` 说明“有 N 个项目正在引用，未删除”；
- 仓库错误：保留确认目标和素材卡，允许再次确认；
- 删除进行中禁用确认和关闭动作，避免重复提交；
- 上传、初始目录加载和删除结果合并时继续按 record ID 去重。

## 5. 信任与数据边界

- asset ID 仅作为 IndexedDB 键使用，不拼接选择器、路径或 HTML；
- 页面不展示项目 ID，只展示引用数量；
- 删除不访问网络、不触发 LibTV CLI，也不撤销远程资源；
- 项目中的资产快照仍是项目可恢复性的权威组成；
- 目录删除能力不用于绕过项目包导出或真实生成确认。

## 6. 可访问性

- 删除按钮名称包含素材名；
- 对话框具备 `role=dialog`、`aria-modal`、标题与影响说明；
- 初始焦点、Escape、取消和成功后的焦点返回明确；
- 版本列表使用嵌套列表和文字状态，不只靠颜色；
- 异步反馈使用 `role=status` 或 `role=alert`。

## 7. 验收标准

1. 一个节点的所有版本均可见，按最新优先排列并标识当前版本。
2. 版本展示提示词、时间、素材和生成任务来源。
3. 删除未引用素材会原子移除目录记录和页面卡片。
4. 任一项目引用存在时删除被拒绝，项目和素材均不改变。
5. 删除确认具备键盘取消、焦点返回和防重复提交。
6. 上传、去重、搜索筛选、跨项目添加、项目快照和任务历史不回归。
7. 第 6 阶段完成后路线图推进到第 7 阶段。
8. 聚焦 Vitest、全量 Vitest、typecheck、build、lint 与 diff-check 全部通过后独立提交。

## 8. 非目标

- 删除或撤回远程 LibTV 素材；
- 自动删除项目引用或级联清理节点版本；
- 从历史页恢复旧版本；
- 素材重命名、标签、收藏、云同步或团队权限；
- 公开部署或合并主分支。
