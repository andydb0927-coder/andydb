## 官方核对（2026-08-28）

| 能力 | 官方契约 | 本批实现 |
| --- | --- | --- |
| 音色 | `speaker` 使用官方 ID | Vivi 2.0、云舟 2.0、少年梓辛 2.0、解说小明 2.0；旧中文别名仍可读取 |
| TTS 音调 | `req_params.additions` 为 JSON 字符串，其中 `post_process.pitch` 为 -12～12 整数 | 新增音调滑杆；默认 0 不改变旧请求 |
| 音频生成音调 | `audio_config.pitch_rate`，-12～12 整数 | 同一滑杆，按 provider 映射 |
| 语速、音量 | `speech_rate` / `loudness_rate`，-50～100 | 保留已验证换算，滑杆数值真实进入请求 |
| 音频格式 | mp3/wav/pcm/ogg_opus；ogg 固定 48000 Hz | 选项按 manifest/格式限制；裸 PCM 保留下载，浏览器无法解码时明确提示转换 WAV，不假装试听成功 |
| 试听 | 官方音色目录没有可直接复用的静态音频 URL | 复用本项目已经生成且音色相同的成功结果；无样音时禁用并说明，不发起 TTS、不用系统音色冒充 |

## 交互与数据

1. 音色选项显示名称与官方 ID；选中立即写节点。试听只播放已有音频，切换/卸载停止，播放失败有中文提示。
2. 语速/音量/音调为可键盘操作滑杆；模型切换按 manifest 恢复默认值；输入焦点不触发画布快捷键。
3. 结果信息卡显示媒体实际时长、采样率、格式和对应成功任务成本。缺字段显示“未读取/未提供”，不拿目标时长充当结果时长。
4. 本地工具保留截取与 0.5～2 倍变速，增加淡入/淡出（以输出时长为基准）、峰值归一化至 -1 dBFS。Web Audio 离线渲染增益包络；归一化保持声道相对音量、静音不放大、不削波。预览不保存，导出才创建 WAV 资产与节点；重复点击、切换项目/画布、取消不得写入过期结果。
5. 版本条显示每版真实波形缩略图、独立音频试听、参数与成本；展开才解码，收起取消，解码失败显示原因不伪造波形。恢复切换媒体、提示词、音色、速度/音量/音调。生成中不能恢复；可一次撤销，不发起生成；刷新保留。
