## 0. 站点地图（全部页面层级）

```
liblib.tv
├── /                    首页（Hero + 特性轮播 + Agent + TV Show）
├── /project             项目页（登录后：项目卡片/文件夹）
├── /canvas?spaceId=…    画布工作台（登录后，二级界面，已由 Codex 拆解）
├── /skill               Skills 页（Agent 输入区 + Tab + 分类 + 卡片流）
├── /activity            创作者挑战赛列表页
├── /activity/:id        挑战赛详情页（赛事落地页）
├── /detail/:id          作品详情页（视频播放器 + 推荐流）
│   └── 查看制作过程     创作过程页（只读画布视图）
├── 积分超市             顶栏入口（登录后可用）
├── 开通会员             顶栏入口（登录后可用）
├── 注册/登录            弹窗（dialog）
└── 帮助                 侧边栏底部（登录后展开菜单）
```

## 2. 首页 `/`

### 2.1 Hero 区
- 主标题："只需一张画布 连接你的多种创意想法"
- 主按钮："新建画布创作"
- 6 个功能入口按钮（带角标分类）：
  1. SD 2.5 独家·直出 5 分钟——原生直出 5 分钟超长视频
  2. SD 2.5·片段重拍——锚点锁定重拍，专业级可控编辑
  3. SD 2.5 独家·智能引用 AutoLink——基于参考内容名称和特征自动匹配引用
  4. 讲解视频——自动配画面，秒出爆款讲解视频
  5. 素材混剪——产品素材一键剪成视觉追踪广告
  6. 独家·逐帧拉片——智能提取视频亮点

### 2.2 特性轮播
- 4 张卡片轮播：Seedance 2.5 全新上线 / 导演台（复杂构图一键搞定）/ Blender 插件（专业 3D 预演一键导入）/ Minimax H3（高性价比）
- 5 个轮播指示点 + 上一张/下一张按钮

### 2.3 LibTV Agent 区
- 标题 "LibTV Agent" + "查看全部"（→ /skill）
- 输入区：添加附件按钮 + 文本框"说出你的创意" + 发送按钮（空文本禁用）
- 三分类 Skill 展示（每类"共 N 个"计数 + 2 张卡片）：
  - 专业影视（共 29 个）
  - 商业广告（共 23 个）
  - 音乐 MV（共 4 个）
- Skill 卡片字段：封面图 + 类型标签（视频/SD 2.5）+ 名称 + 描述 + 作者 + 使用数 + "使用这个 Skill"按钮 + "查看详情"（点击卡片）

### 2.4 TV Show 作品区
- 分类标签栏（可横向滚动）：全部 / Seedance 2.5 / 走，我们扫街去 / 精选画布 / 专业影视 / 短剧漫剧 / 商业广告 / 动漫游戏 / 教育生活 / TV工具箱
- 搜索框 + 搜索按钮
- 作品卡片（瀑布流，16+ 个）字段：
  - 视频封面（hover 播放）
  - 播放数（右下角）
  - 作者头像 + 作者名 + 认证徽章（"专业"/"先锋"）
  - 作品标题（部分含奖项标签如"AI影像狂飙季-短片单元-最佳影片"、模型标签"SD 2.5"、Skill 标签"Skill: 是枝裕和电影美学"）
  - "查看创作过程"按钮

- 大标题："Skill 就位，ready when you are"

## 5. 创作者挑战赛 `/activity`

- 标题"挑战赛" + 状态筛选：进行中 / 已颁奖
- 挑战赛卡片：状态标签 + 卖点文案（emoji 开头）+ 活动名 + 合作方（如"高德 x LibTV x 阿里云"）
- 实测 8 个活动：瓦漫节·无畏契约觉醒计划、Skill 导演大师赛、走我们扫街去、广告"导演"请就位、AI 漫剧精卫计划、大乱斗 vol.2/vol.1、Seedance 2.0 影像狂飙季
- 底部"没有更多了"（分页结束态）

## 6. 挑战赛详情 `/activity/:id`

赛事落地页结构：
- 返回按钮 + 活动标题 + "去创作"按钮 + 倒计时（"预计今天结束"）+ 活动时间
- 活动介绍（富文本）：📢开场 + 活动日历（征集期/评选期/公示期/发放期）
- 活动赛道（3 片场，各有适用方向+创作重点）：爆款片场（接单开拍）/ 效率片场（单点神器）/ 大师片场（殿堂美学）
- 如何参赛（5 步指引，含外部链接：飞书 wiki/表单）
- 活动奖励（分级）：特等奖（票房之王 2 万现金）· 特别奖（金算盘/大师公开课）· 单元奖（金导筒，3 片场名额+金额）· 入围奖（场记板，40 条×500 元）
- 活动详情链接（外部文档）+ 社群指引（客服入口）

## 7. 作品详情 `/detail/:id`

- 沉浸式布局：模糊背景图 + 中央视频播放器
- 返回按钮 + 作者（头像/名字/认证徽章"专业"）+ 作品标题 + 更新时间 + "含 AI 生成内容"标注
- "立即观看"按钮 + "查看制作过程"按钮
- 左右切换按钮（上一个/下一个作品）
- 底部推荐流：11 个作品缩略图（点击切换）

## 8. 创作过程页（作品详情内"查看制作过程"）

**这是画布只读分享视图**：
- 顶部：作品标题 + "只读模式，如需创建请点击 复制项目"
- 画布：分组信息（"分组 2 个节点"）+ 节点（视频节点 91/26/21…50+ 个）
- 时间分组：按日期分组历史节点（6月21日(10) 等）
- 视图控制：连线显隐切换 + 缩放（10%）
- 未登录用户看不到，触发登录弹窗

## 9. 登录弹窗
