# 无线画布 LibTV 功能域第 2 阶段：账号与空间设计规格

日期：2026-08-13

状态：已确认，进入实施

范围：完善 `/account` 的本地身份、个人空间、设备偏好、团队/账号能力边界；不新增未经授权的真实登录、支付、云同步或外部写入。

## 1. 参照证据

已登录 LibTV 首页和项目空间的只读核对显示：

- 全局侧栏包含首页、项目、Skills、活动、最近项目、新建项目和帮助；
- 账号入口聚合个人身份、团队切换、会员、积分、存储、Access key、个人中心、订阅、模式、AI 水印、CLI/Skill、通知与退出；
- 项目空间包含全部项目、新建文件夹、开始创作、项目卡片和更新时间。

本阶段只复刻这些信息域与导航关系，不复制用户身份、余额、项目名称、会员价格、头像或私有数据。项目卡片、文件夹和项目管理属于第 3 阶段。

## 2. 当前基线

`/account` 已具备：

- 项目、节点、素材和评论统计；
- 本地会员状态与权益矩阵；
- 本地协作者角色、共享链接和项目包；
- 工作区备份与恢复；
- 所有数据保存在当前浏览器 Dexie 中，页面已声明无账号后端、云同步和真实支付。

缺口是身份和空间语义不完整：用户看不到当前究竟以什么身份工作、是否连接云账户、团队空间是否可用，也无法设置设备级创作偏好。

## 3. 选定方案

采用“本地身份卡 + 单一个人空间 + 设备偏好 + 能力边界”方案：

1. 明确显示当前为“本地设备身份”，不是在线账户；
2. 个人本地空间是唯一活动空间，承载现有 Dexie 项目；
3. 团队空间、云账户、Access key、真实积分/账单均显示为未接入，不提供虚假操作；
4. 用户可编辑仅本设备显示的创作者名称，并设置 AI 标识和站内状态提醒；
5. 设备偏好使用版本化 localStorage，项目、会员、协作和素材继续使用 Dexie；
6. 提供项目空间、素材、Agent/CLI 和本地备份的真实导航入口。

不新增 App 自有登录表单。当前静态 Vite 架构没有可信的服务端会话和授权层，伪造邮箱/密码流程会制造错误安全感。未来接入托管身份时，认证和授权必须在服务端完成。

## 4. 设备身份与偏好模型

```ts
interface LocalAccountPreferences {
  version: 1
  displayName: string
  aiWatermark: boolean
  inAppNotifications: boolean
  updatedAt?: string
}
```

- 存储键：`wireless-canvas:local-account-preferences:v1`；
- 默认名称：`本机创作者`；
- AI 标识默认开启；站内提醒默认开启；
- 名称去首尾空格，空名称回退默认值；
- 损坏 JSON、未知版本或 storage 异常不得阻塞 `/account`；
- 只保存设备偏好，不保存邮箱、手机号、密码、令牌、真实 UUID 或支付信息；
- `storage` 事件同步其他标签页。

## 5. `/account` 页面结构

### 5.1 本地身份

- 显示本地头像字母、创作者名称、状态“本地模式”；
- 清楚说明未登录、未连接云账户；
- 名称编辑表单具有稳定标签和保存反馈；
- 不生成可冒充平台账号的 ID。

### 5.2 空间状态

- “个人本地空间”为活动空间；
- 汇总本地项目、节点、素材和估算存储量；
- “团队空间”显示未接入及所需后端能力；
- 提供到项目空间和素材库的真实链接。

### 5.3 创作偏好

- “生成内容默认添加 AI 标识”作为设备级偏好；
- “显示站内任务状态提醒”只控制应用内提示，不请求系统通知权限；
- 设置变更即时写本地，并提供状态反馈；
- Access key 与 CLI 仅链接现有 Agent/CLI 说明，不生成密钥。

### 5.4 既有会员、协作和备份

保留现有本地模拟会员、协作者、项目包和备份能力，并继续明确“本地模拟、无真实支付、无实时多人”。

## 6. 可访问性与响应式

- 身份、空间、偏好、会员、协作和备份使用独立命名 section；
- 所有开关使用原生 checkbox 和可见文字；
- 保存按钮、链接和状态反馈可键盘操作；
- 720px 以下身份/空间卡改为单列；
- 状态不能只用颜色表达；
- 页面加载错误保留现有本地数据，不渲染虚假零值成功态。

## 7. 验收标准

1. `/account` 明确显示本地身份、个人本地空间和云账号/团队未接入边界。
2. 编辑名称、AI 标识和站内提醒后刷新仍保留。
3. 损坏或不可用 storage 时页面安全回退。
4. 项目/素材统计和本地存储估算来自真实项目数据。
5. 项目空间、素材库、Agent/CLI 链接可用。
6. 既有会员、协作者、共享和备份测试保持通过。
7. 任务编排默认状态推进为第 2 阶段完成、第 3 阶段进行中。
8. 聚焦 Vitest、全量 Vitest、typecheck、build 和 diff-check 通过后独立提交。

## 8. 非目标

- 真实注册、登录、登出、OAuth、邮箱或手机号验证；
- 真实团队邀请、云空间隔离、积分、充值、账单、发票或支付；
- 生成或展示真实 Access key；
- 第 3 阶段的文件夹、项目搜索、排序、重命名和删除；
- 公开部署或合并主分支。
