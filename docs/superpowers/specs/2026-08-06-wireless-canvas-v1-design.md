# 无线画布 V1 产品设计规格

日期：2026-08-06  
状态：已批准
目标用户：AI 短片与影视创作者  
选定方向：方案 2「自由无限画布」

视觉参考：[wireless-canvas-v1-direction-2.png](../../../design-references/wireless-canvas-v1-direction-2.png)

## 1. 产品目标

无线画布帮助 AI 短片创作者把分散的角色参考、场景设定、分镜图、视频片段和成片组织在同一张空间画布中。用户不需要记住不同模型的参数，也不需要在多个工具之间复制素材；他们从一句创作意图开始，在画布上逐步生成、调整、串联并导出短片。

V1 的成功标准是：首次用户可以在 10 分钟内完成一条最小闭环——创建项目、生成两个相互连续的分镜、生成其中一个视频片段，并进入成片预览。

## 2. 设计原则

1. **画布是产品本体。** 项目打开后直接进入画布，不用仪表盘包裹核心创作。
2. **AI 按需出现。** AI 导演使用底部悬浮输入框和节点旁的上下文操作，不常驻占用大面积侧栏。
3. **空间关系表达创作关系。** 节点位置、连线和分组承担角色、场景、分镜与成片之间的结构表达。
4. **专业但不暴露模型复杂度。** 默认显示创作语言，如镜头、时长和连续性；模型、采样和成本放入高级设置。
5. **所有生成结果都可修改。** AI 只创建草稿，用户可以替换素材、改提示词、断开连接、重排顺序和重新生成。

## 3. V1 信息架构

```text
无线画布
├── 项目入口
│   ├── 新建项目
│   │   ├── 输入创作意图
│   │   └── 选择可选配方
│   └── 最近项目
├── 项目画布（默认主页）
│   ├── 素材节点
│   │   ├── 角色参考
│   │   ├── 场景设定
│   │   └── 外部图片或视频
│   ├── 创作节点
│   │   ├── 文本
│   │   ├── 分镜
│   │   └── 视频片段
│   ├── 关系
│   │   ├── 连线
│   │   ├── 分组
│   │   └── 时间线顺序
│   ├── AI 导演
│   └── 项目设置
└── 成片预览
    ├── 播放器
    ├── 时间线
    ├── 片段检查
    └── 导出设置
```

V1 不包含社区、公开模板市场、多人协作、模型交易、会员体系和创作者收益。这些能力不会出现在导航中，也不会使用占位入口暗示。

## 4. 三个核心页面

### 页面 A：项目入口

**用户任务：** 用一句话创建新短片，或继续最近项目。

**主要结构：**

- 顶部仅保留品牌、帮助和账户入口。
- 主区域提供一个大输入框，提示语为“描述你想创作的短片……”。
- 输入框下只展示三个可选配方：电影感叙事、品牌氛围片、角色概念预告。
- 下方展示最近项目的横向列表；没有项目时展示一条完整示例，而非空白卡片。
- 唯一主操作是“创建项目”。创建后直接进入页面 B。

**关键状态：**

- 空输入：允许从配方开始，但创建前要求补充主题。
- 正在解析：显示“正在整理角色、场景与镜头结构”，并允许取消。
- 解析失败：保留原始输入，给出“重试”和“直接进入空白画布”。

### 页面 B：项目画布

**用户任务：** 组织素材并生成连续分镜与视频片段。

**主要结构：**

- 画布占据至少 80% 视口，使用低对比度点阵背景。
- 左侧为紧凑悬浮工具栏，只包含选择、文本、图片、分镜、视频、连线和分组。
- 节点从左上向右下自然延展：角色参考 → 场景设定 → 分镜 → 视频片段 → 成片预览。
- 选中节点后，在节点旁出现“重生成、扩展镜头、加入时间线”等上下文操作。
- 底部悬浮 AI 导演输入框，文案为“告诉我下一步要做什么……”。
- 顶部只提供项目名、撤销/重做、保存状态、预览和导出。

**交互约束：**

- 滚轮缩放以指针位置为中心；空格拖动画布；框选支持批量移动。
- 连线表示输入依赖，不自动等同于时间顺序；加入时间线后才决定播放顺序。
- 生成任务绑定节点，用户移动、缩放或浏览其他区域时任务继续运行。
- 删除有下游依赖的节点时，必须说明影响范围并提供取消。

**关键状态：**

- 生成中：节点显示进度和取消，不锁住整张画布。
- 生成失败：节点保留提示词、参考素材和错误摘要，可原位重试。
- 引用失效：连线变为警示状态，下游结果保留但标记为“来源已变化”。
- 离线或保存失败：顶部显示明确状态，继续保留本地编辑记录。

### 页面 C：成片预览与导出

**用户任务：** 检查片段连续性，调整顺序并导出成片。

**主要结构：**

- 左侧为大播放器，支持逐帧、循环当前片段和前后镜头对比。
- 下方为单轨时间线；V1 只支持主视频轨和一条音频轨。
- 右侧为当前片段检查面板，显示时长、画幅、来源节点和连续性提醒。
- 顶部提供“返回画布”，保持当前镜头在画布中的定位。
- 主操作是“导出影片”，设置仅包含分辨率、画幅、帧率和是否包含水印。

**关键状态：**

- 缺少片段：时间线显示缺口并可跳回对应画布位置。
- 画幅不一致：导出前给出统一裁切或逐镜确认。
- 渲染中：展示整体进度、预计剩余时间和后台运行说明。
- 渲染失败：保留成功片段，允许从失败片段继续。

## 5. 核心组件边界

| 组件 | 职责 | 依赖 |
|---|---|---|
| Project Launcher | 收集创作意图并创建项目草稿 | 配方定义、项目服务 |
| Canvas Viewport | 缩放、平移、选择和空间定位 | 节点与边数据 |
| Node Renderer | 渲染不同节点类型及其状态 | 资产、生成任务 |
| Edge Layer | 表达输入依赖与失效状态 | 节点端口 |
| AI Director | 将自然语言转换为节点操作建议 | 当前选择、项目上下文 |
| Generation Queue | 管理生成、取消、重试和进度 | 模型适配层 |
| Timeline | 管理播放顺序与片段时长 | 视频节点 |
| Preview Export | 播放、检查和导出 | 时间线、渲染任务 |

画布视图不直接调用具体模型。所有生成请求先进入 Generation Queue，再由模型适配层处理；这样后续更换供应商不会改变画布交互。

## 6. 数据与状态流

```text
创作意图
→ 项目草稿
→ 角色/场景节点
→ 分镜节点
→ 视频节点
→ 加入时间线
→ 成片预览
→ 导出任务
```

核心实体包括 Project、Node、Edge、Asset、GenerationJob、TimelineItem 和 ExportJob。节点只保存对资产与任务的引用，生成历史保留为可回退版本，不覆盖旧结果。

## 7. 可访问性与输入方式

- 所有悬浮操作必须可以通过键盘打开，不能只依赖鼠标悬停。
- 节点选择、连线和生成状态要同时使用文字或图标，不只依赖颜色。
- 正文与弱化文字仍需达到可读对比度；深色界面不使用过低亮度灰色。
- 支持 200% 缩放时查看节点详情；画布缩放与浏览器页面缩放必须分开。
- 提供“节点列表”替代视图，供键盘与读屏用户按结构顺序浏览项目。

## 8. 验收场景

1. 新用户输入短片创意并创建项目后，画布出现角色、场景和首个分镜草稿。
2. 用户可以选择分镜节点、补充参考图、重新生成，并保留上一版本。
3. 用户可以扩展第二个镜头，将其中一个镜头生成视频并加入时间线。
4. 用户可以进入预览、调整两个片段顺序并发起 1080p 导出。
5. 任一生成任务失败时，其他节点仍可编辑，失败节点可原位重试。
6. 用户刷新页面后，节点位置、连线、版本和任务状态保持一致。

## 9. 实施边界

第一实施周期只完成上述三个页面和最小闭环。真实模型调用可以先通过一个图像模型和一个视频模型接入；配方只使用本地固定配置。社区、协作、计费和复杂多轨剪辑独立立项，不进入本规格。
