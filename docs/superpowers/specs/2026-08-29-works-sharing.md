# 批次9：作品展示与分享

## 范围与数据边界

- 复用 `publishedWorks` 的不可变项目/时间线/工作流快照，不改生成 Provider，不调用真实 API。
- `/works` 展示本地个人作品（不把首页内置示例算作个人作品）；卡片含封面、标题、摘要、实际生成任务记录的模型标签、项目创作时间。
- 关键词（标题/简介/作者/标签/模型）、模型、收藏、公开标记筛选，最新/最早创作、标题排序。筛选不改变统计口径。
- `/view/:workId` 保留只读画布快照，补创建者、本地收藏/公开标记、相关作品和导出。加载或写入失败明确反馈；切路由不显示上一作品的异步结果。

## 兼容与交互

- 新增可选 `PublishedWork.visibility: public | private`；旧数据缺失按私密解释；不复用 `status`（published/unlisted 为发布/下架语义）。重新发布保留可见性与收藏。
- 收藏复用 `viewer.favorited` 和事务接口；公开标记用事务写入。操作期间阻止重复提交，失败不伪造成功状态。仅当前浏览器存储，不提供云端发布、权限隔离或跨设备共享。
- 内置示例按现有固定 ID 识别，首页示例与详情行为不变。个人详情相关作品只取其他个人已发布作品，优先共同标签/模型，无重复凑数。

## 导出与统计

- PNG 长图真实绘制封面和文字，按内容计算高度，含创建者、模型、时间、摘要及“二维码预留位”（非可扫描码）。外部封面 CORS/过期失败明确提示，不生成空白伪成功文件。
- 项目包复用 `createWorkflowSnapshot`，保留原格式与版本，附 `assetIds` 清单、作品信息、独立时间线；单 JSON，旧导入器仍能识别。基于发布快照而非后续编辑项目；外部 URL 不是媒体二进制备份。
- 数据看板以个人已发布作品冻结的 `jobs` 为数据源。按项目/任务 ID 去重；模型使用次数统计成功任务（不是图片张数）。优先记录的 `creditsSpent`，成功任务缺失时用 `estimatedCost`；无金额则记未知，不伪造收费。显示估算及数据范围，非供应商账单。
- 用 CSS 条形图与文本数值，不添加依赖。帮助中心“发布”分类补收藏、公开标记、PNG、项目包与统计说明。
