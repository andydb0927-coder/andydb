# Liblib 画布录屏对齐规格（2026-08-20）

## 1. 证据边界

- 证据源：用户提供的 51 秒 Liblib 登录态画布录屏 `录屏2026-08-20 14.43.13.mov`。
- 本规格只把录屏中可直接观察到的界面与交互作为对齐契约；没有在录屏中出现的后端生成、积分扣除、Skill 调用不作推断。
- 本地实现继续使用演示数据，不触发真实生成或积分消耗；既有节点、依赖连线、生成队列、项目持久化、预览与导出能力必须保持。

## 2. 录屏时间线与实测结构

### 00–03 秒：空画布与右键菜单

- 暗色点阵画布，顶部为紧凑工作区信息与账户操作，底部为居中图标工具坞。
- 空画布中央提示“双击画布 自由生成节点”，并展示故事脚本生成、角色三视图、全能参考生视频、音频生视频四个建议入口。
- 空白处右键菜单顺序为：上传、保存到我的资产、添加节点、分隔线、撤销、重做、粘贴。
- 不可用操作保留在原位置并呈禁用态，而不是从菜单移除。

### 04–06 秒：底部添加节点与图片节点双态

- 点击工具坞“+”后直接显示纵向“添加节点”列表：文本、图片、视频、智能剪辑 Beta、导演台 NEW、逐帧拉片 SD2.5、音频、脚本、素材库；下方为“添加资源”：上传、从生成历史选择。
- 新图片节点的折叠媒体卡显示：浮动标题、预览占位、左右端口、尝试区“图生图 / 图片高清”。
- 当前图片节点在卡片下方打开独立生成参数框，顶部为参考/标记/风格，底部为 Lib Image、16:9 · 标准画质 · 2K · 1张、翻译、设置、成本 18 与圆形生成按钮。

### 08–18 秒：端口拖出并创建下游节点

- 悬停节点右侧端口出现“+”。
- 从输出端口拖到画布空白处，终点显示“引用该节点生成”菜单：文本、图片、视频、智能剪辑、导演台、逐帧拉片、音频、脚本；参考节点禁用。
- 选择类型后在释放位置创建节点，并以一条上游到新节点的有向连线连接。
- 新节点成为唯一当前节点；其生成参数框显示已继承的参考数量。创建节点与连线是一次可撤销事务。

### 18–25 秒：视频节点双态与生成模式

- 视频节点未选中时保持小型媒体卡；选中时在下方出现独立生成参数框。
- 参数框顶部入口顺序为：参考、标记、特效、角色库、运镜；提示区支持 `@引用素材`。
- 底部显示模型、生成模式、16:9 · 720P · 5s · 1个、声音、辅助设置、成本 135 与圆形生成按钮。
- 生成模式菜单顺序为：文生视频（当前上下文不可用）、全能参考（默认）、图生视频、首尾帧、图片参考。
- 模型菜单至少呈现录屏可见的 Seedance 2.5、Seedance 2.0 VIP、Minimax H3、Seedance 2.0 Fast VIP、Seedance 2.0 Mini、Happy Horse 1.1、Happy Horse 1.0。

### 27–38 秒：框选、分组和排列

- 框选多个节点后可建立一个带圆角边框的组合选择框。
- 组合工具条顺序包含：排列、保存到资产、创建副本、复制、打组、添加到 Chat。
- 排列子菜单为：宫格排列、水平排列、垂直排列；选择后节点位置更新但原依赖关系保持。
- 组合框右侧保留“+”继续建立下游内容。

### 40–47 秒：重复下游创建与图关系保留

- 任一节点均可重复通过输出端口创建下游节点。
- 多次创建后节点可以重新排列；连线始终跟随端口更新，拓扑不丢失。
- 49 秒后的系统截图选区属于 macOS，不是 Liblib 产品功能。

## 3. 本次实现验收契约

1. 右键菜单按录屏顺序恢复，节点右键仍允许删除；保存资产、撤销、重做、粘贴拥有真实禁用/可用语义，Escape 与外部点击关闭并回焦。
2. 工具坞添加按钮使用紧凑纵向节点清单；双击空白处仍保留四项自由生成建议选择器。
3. 原生端口连接释放在空白处时打开“引用该节点生成”；创建新节点、连线、选择与引用计数一次完成，撤销一次完全恢复。
4. 空视频节点与有结果视频节点均采用折叠媒体卡；只有当前节点显示独立参数框。视频参数默认值与录屏一致，既有媒体处理/帧操作等扩展能力保留。
5. 分组组合框提供录屏工具条与三种排列；创建副本与复制使用既有本地复制事务，保存到资产/添加到 Chat 给出不产生远端副作用的本地反馈。
6. 连接命中层、键盘可访问性、721×778 与 200% 布局可达性不得回归。
