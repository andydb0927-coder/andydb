# 无线画布 LibTV 功能域第 11 阶段：创作者主页设计规格

日期：2026-08-13

状态：已确认，进入实施

## 1. 基线与缺口

社区已覆盖作品流、全文搜索、标签筛选、最新/最热排序、作品详情、预览、浏览计数、点赞、收藏、推荐和我的作品管理。但作者只是静态文字，社区页层级缺少创作者主页。

## 2. 选定方案

- 新增 `/discover/creator/:author` 页，从已发布作品派生创作者资料；
- 显示作者名、认证状态、作品数、总浏览、总点赞、总收藏、常用标签和作品目录；
- 作品卡和作品详情中的作者名均链接主页；
- 匹配使用解码后的精确作者名，不把标题/标签命中的其他作品算入；
- 作品依旧由 `WorkCard` 呈现，保持详情入口一致。

## 3. 边界

- 创作者资料由本地已发布快照派生，不创建第二份账号数据；
- 认证状态为作品快照的联集；
- 不伪造关注、粉丝、私信或云端社交关系；
- 不自动触发任何互动或对外写入。

## 4. 验收标准

1. 作品卡与详情页作者名可达编码后主页。
2. 主页仅展示同名作者的已发布作品。
3. 作品数与三项互动汇总准确。
4. 认证状态、常用标签和作品目录可访问。
5. 未找到作者与仓库失败都使用不泄露内部信息的状态。
6. 第 11 阶段完成后路线图推进至第 12 阶段。
7. 聚焦/全量 Vitest、typecheck、build、lint、diff-check 通过后独立提交。

## 5. 非目标

- 关注、取消关注、粉丝数或私信；
- 远程账号、云端主页或公网同步；
- 修改作品的作者快照。
