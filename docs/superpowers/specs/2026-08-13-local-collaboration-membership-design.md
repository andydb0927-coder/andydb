# 无线画布步骤 6：本地协作与会员框架设计规格

日期：2026-08-13  
状态：依据用户“不要询问用户，直接完成”执行  
范围：在现有 Dexie 项目、素材、工作流、时间线与 `/account` 入口之上，建立不依赖账号后端的本地协作、会员和备份框架。

## 1. 基线盘点

- `/account` 已注册在平台壳层中，当前只读取 `ProjectRepository.listRecent()` 展示项目数。
- Dexie v6 已保存项目、素材库、工作流运行、专业时间线和本地作品；没有账号、团队、订阅或评论表。
- 画布已有节点选择，预览页已有片段选择；它们可以作为评论标记的本地目标，不改变项目核心快照结构。
- 时间线 JSON / EDL 和预览录制均在浏览器端完成；工作流运行使用本地 Demo 适配器。

## 2. 目标与边界

### 2.1 目标

1. 生成带版本号的项目 JSON 包，包含项目画布、项目素材引用、关联素材库记录、专业时间线、协作者和评论；支持下载、共享链接及导入恢复。
2. 每个项目持久化所有者、编辑者、只读三类本地模拟协作者；所有者不可被移除。
3. 节点和时间线片段可添加、查看和解决评论，并显示对应评论数量标记。
4. 提供免费版、创作者版、专业版功能矩阵；订阅、取消和续期均只写本地 Dexie。
5. 对高级导出和批量工作流执行真实等级检查；被门控时禁用动作并提供 `/account` 升级入口。
6. 将 `/account` 升级为个人中心，集中显示会员、项目统计、协作者、项目共享、导入恢复和全工作区备份。

### 2.2 非目标

- 不登录、不上传、不建立 WebSocket/云同步，不声称跨设备实时协作。
- 不调用 LibTV、外部 API、真实支付、计费或积分接口。
- 分享链接仅把项目包编码在当前应用 URL 的 hash 中；接收方仍需在本地导入。
- 不运行 Chromium E2E；自动验收只运行 Vitest、typecheck 和 build。

## 3. 数据模型与 Dexie

数据库升级到 v7，新增：

```ts
collaborators: 'id, projectId, role, updatedAt'
changeComments: 'id, projectId, targetType, targetId, status, createdAt'
membership: 'id, plan, status, updatedAt'
```

- `Collaborator.role`: `owner | editor | viewer`。每个项目通过仓储确保一个固定的“本机所有者”。
- `ChangeComment.targetType`: `node | clip`；目标 ID 与项目 ID 分开索引，评论正文去首尾空白。
- `ChangeComment.status`: `open | resolved`；解决操作保留历史，不物理删除。
- `MembershipSubscription`: 单例 `local-membership`；没有记录时视为免费版 active。本地取消立即回落免费版并保留最近一次付费等级，续期重新激活该等级。

## 4. 项目包、共享与备份

`LocalProjectPackage` 使用 `schemaVersion: 1`，包含：

- `project`: 完整 `Project`，覆盖节点、边、版本、项目素材引用和基础时间线；
- `timeline`: 可选专业 `TimelineProject`；
- `libraryAssets`: 项目引用到的素材库记录；
- `collaboration`: 项目协作者和评论；
- `exportedAt` 与来源说明。

导入先做结构校验，拒绝未知版本、缺少项目 ID/数组字段或目标不属于包内项目的协作记录；然后在单个 Dexie 事务中恢复全部可用记录。项目包导入按原项目 ID 恢复，因此可用于覆盖式备份恢复，界面明确提示该语义。

共享链接格式为 `#local-share=<encodeURIComponent(JSON)>`，仅本地传递，不上传服务器；超大媒体 Data URL 可能使链接过长，因此同时保留 JSON 下载作为可靠路径。全工作区备份为多个 `LocalProjectPackage` 的版本化集合。

## 5. 会员与权益

| 能力 | 免费版 | 创作者版 | 专业版 |
| --- | --- | --- | --- |
| 本地项目与基础时间线 JSON | 可用 | 可用 | 可用 |
| 项目包、协作角色与评论 | 可用 | 可用 | 可用 |
| EDL / 预览录制高级导出 | 不可用 | 可用 | 可用 |
| 多节点或并行批量工作流 | 不可用 | 不可用 | 可用 |

`canUseFeature(plan, feature)` 是唯一纯函数判定源。时间线面板对 EDL 和预览录制应用 `advanced-export`；画布工作流对多节点或并行运行应用 `batch-workflow`。基础单节点串行运行和时间线 JSON 保持免费可用。

## 6. 界面与可访问性

- 所有本阶段界面持续展示“本地模拟”，避免被误认为真实账号、支付或多人在线能力。
- `/account` 分为会员状态、功能矩阵、项目统计、项目协作/分享和备份恢复区。
- 协作者表单使用可访问姓名输入和角色选择；所有者操作禁用并说明。
- 画布评论面板跟随当前主选节点，时间线评论面板跟随当前选中片段；标记显示未解决数，表单和解决按钮具有稳定中文名称。
- 门控信息包含所需等级、当前等级和前往会员中心链接，不能只用颜色传达。

## 7. 验收

1. 纯模型测试覆盖等级矩阵、订阅状态机、包校验/共享链接和评论输入规则。
2. Dexie 测试覆盖 v6 升级、协作者、评论、订阅和项目包事务恢复。
3. 组件测试覆盖 `/account` 的会员操作、统计、协作者、共享/导入/备份，以及节点/片段评论。
4. 门控测试证明免费版不能触发高级导出/批量工作流，升级等级后可触发。
5. 全量 Vitest、typecheck、build 和 `git diff --check` 通过；不 commit。
