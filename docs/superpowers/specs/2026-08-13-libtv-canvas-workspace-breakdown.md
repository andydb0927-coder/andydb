# Liblib 画布工作台深度拆解

日期：2026-08-13  
目标页面：`https://www.liblib.tv/canvas?spaceId=5392579&projectId=97e20393b81b4d13a97f06518772b979`

## 1. 调研边界与结论

本次基于已登录的 Liblib 真实项目做交互审计，覆盖工作流、故事板、画布节点、上下文工具、资产、历史记录、Agent、快捷键和视图控制。为避免改变用户的云端数据或消耗积分，本次没有执行生成、发布、分享、上传、购买或发送 Agent 消息。审计过程中打开的临时高清/全景配置节点已删除，原项目仍只保留原有的“角色图”和“角色三视图”节点。

核心判断：Liblib 的二级画布页不是单一“节点编辑器”，而是由四层协同组成的 AI 内容生产工作台：

1. 平台层：项目、画布、账号、积分、发布与分享。
2. 编排层：无限画布、节点、依赖连线、分组、视图与快捷键。
3. 资源层：素材库、角色库、历史生成、工具箱和上传入口。
4. 生成层：上下文工具、模型参数、Agent、故事板和后续编辑。

## 2. 整体布局

| 区域 | 位置 | 主要职责 | 交互特征 |
| --- | --- | --- | --- |
| 项目与模式栏 | 左上 | 项目命名、画布管理、工作流/故事板切换 | 固定悬浮，模式切换不离开工作台 |
| 平台操作栏 | 右上 | 发布、分享、积分、账号、Agent | 菜单/抽屉式展开 |
| 中央画布 | 全屏主体 | 节点编排、依赖关系、选择与上下文动作 | 无限缩放、拖拽、框选、快捷键 |
| 创建工具坞 | 中下 | 添加节点、移动、工具箱、素材与历史 | 紧凑悬浮，二级菜单向上展开 |
| 视图控制栏 | 左下 | 素材管理、自动排布、小地图、连线、网格、缩放 | 只改变当前工作区视图，不改内容数据 |
| Agent 面板 | 右侧 | 对话、技能、模型、自动生成策略 | 可开关、可调整宽度，与画布上下文联动 |
| 故事板视图 | 主体替换 | 按文本/图片/视频汇总项目媒体 | 不是传统时间线，而是媒体总览 |

工作台采用深色低干扰背景，主要操作以悬浮胶囊、弹层和可收缩侧栏承载。核心节点操作保持在画布中心，平台级操作被推到四周，降低遮挡。

## 3. 顶部栏

### 3.1 左上项目区

- 品牌入口。
- 项目标题“未命名工作区”，可直接编辑。
- “画布 1”下拉：
  - 新建画布；
  - 当前画布列表；
  - 更多操作：新窗口打开、重命名、复制、删除；
  - 仅剩一个画布时删除不可用。
- 模式切换：
  - “工作流”：节点式生产编排；
  - “故事板”：按媒体类型查看结果。

### 3.2 右上平台区

- 发布/分享菜单：
  - 发布到 Liblib：发布作品并可附带创作过程；
  - 分享链接：允许访问者查看或复制画布。
- 权益/积分商城入口。
- 当前积分余额；详情可查看会员期限、订阅积分、充值积分、模型积分、免费积分、积分管理与消费订单。
- 账号头像菜单：团队/账号、会员、积分、存储、个人中心、发票与订阅、显示模式、AI 水印、CLI 与 Skill、通知、返回 Liblib、退出登录。
- Agent 开关。
- 网络不稳定时会在顶栏附近显示状态提示。

## 4. 中央无限画布

### 4.1 基础对象

- 深色点阵背景，可平移与缩放。
- 节点卡片包含标题、尺寸/类型信息和内容预览。
- 节点之间通过依赖连线表达生成上下文。
- 连线中点提供快速“+”入口，用于在依赖链中插入或继续创建。
- 选中节点后，节点上方显示上下文工具栏。

### 4.2 选择、拖拽与视图

- 单选节点、框选、多选、拖动节点、画布平移、滚轮缩放。
- 支持连接端口创建依赖边。
- 节点移动、连接和删除可以撤销/重做。
- 视图级开关包含小地图、连线显示、吸附网格和缩放预设。
- 画布内的操作与 Agent 的 `@节点`、生成配置中的引用素材、历史结果回填相互连接。

### 4.3 图片节点上下文工具

已观察到以下能力：

- 人像质感：含人像/情绪等子项。
- 720° 全景图：引用素材、描述、模型、比例、画质、分辨率、张数、预设、高级配置、AutoLink。
- 多角度：自定义、鱼眼、俯视、仰视、前/后视等机位，水平环绕、垂直俯仰、景别、提示词开关和重置。
- 打光：智能全局开关、亮度、颜色、主光方向、轮廓光、重置。
- 九宫格：多机位 9 图、故事 4 图、面部 3 图、人物设定、场景设定、产品设定、25 格连贯分镜、电影感灯光修正、人物转身、前后帧演进。
- 高清：Topazlabs、通用模式、2/4/6 倍放大，并显示积分成本。
- 宫格拆分：2×2、3×3、4×4、5×5、自定义。
- 另有编辑/变换/下载/全屏类图标操作；审计时页面未提供可读名称，因此不把图标推断当作确定契约。

设计注意：部分工具在点击后直接创建配置节点，缺少显式预览或“是否创建”的中间确认，容易造成画布污染。复刻时应先打开配置，再由用户确认创建。

## 5. 中下创建工具坞

主入口：添加节点、移动、工具箱、素材库、角色库、历史、快捷键、教程。

### 5.1 添加节点

- 文本
- 图片
- 视频
- 智能编辑（Beta）
- 导演台（NEW）
- 逐帧审阅（SD2.5）
- 音频
- 剧本：新剧本、旧版剧本（Beta）
- 资产库：风格库、特效库
- 添加资源：上传、从生成历史选择

### 5.2 移动

- 移动工具：`V`
- 手型平移：`H`

### 5.3 工具箱

可调整大小的工具弹层，含“我的工具箱”、说明和主题集合。卡片提供直接使用操作。示例包括弧线滑动、电商手机动效、咖啡入场、360° 商品旋转、机械臂、Live2D、瞳孔缩放、鸟群解体、破盒、产品入场、反重力、粒子消散、旅行转场、英雄视角、AI 换装、大师网格和室内可视化。

### 5.4 素材与角色

- 素材库快捷入口：风格库、特效库。
- 角色库：大尺寸选择弹窗，包含已选区域、筛选、最近使用和“应用到画布”；未选角色时操作禁用。

### 5.5 生成历史

- 图片/视频/音频分页；本次账号显示 1827/403/2。
- 日期排序、批量操作、缩略图缩放、按日期分组。
- 单项支持查看、使用和下载。
- 结果可重新发送到画布，形成“生成—沉淀—复用”的闭环。

## 6. 左下管理与视图控制

### 6.1 素材管理侧栏

打开左侧可调整宽度的面板：

- “画布”页：类型筛选、节点搜索、分组折叠、节点列表、定位、更多操作、数量统计。
- “资产”页：个人/Agent、搜索、筛选、文件夹、双击重命名、发送到画布。
- 全局资产弹窗：个人资产库、可灵主体库、搜索、批量、新建、分类筛选、分页、发送到画布。

### 6.2 视图按钮

- 整理画布：`Option + Shift + F`
- 小地图开关
- 连线显示开关
- 吸附网格开关
- 缩放菜单：输入百分比、放大、缩小、适配视图，以及 50%/100%/800% 预设

这些属于本地工作区偏好，不应写入项目内容历史，也不应触发自动保存提示。

## 7. 故事板

“故事板”会替换中央画布，按“文本 / 图片 / 视频”三个区块汇总项目内容：

- 支持区块展开/收起与空状态。
- 图片卡显示尺寸，并保留对白/详情区域。
- Agent 面板可以与故事板同时打开。

证据边界：目标项目中没有出现传统多轨时间线、播放头或剪辑轨道。因此 Liblib 此处应定义为“媒体故事板/项目汇总”，而不能等同于视频编辑时间线；视频排序、剪辑和导出的深入联动需要在有完整素材的项目中另行验证。

## 8. Agent 侧栏

右侧可调整宽度的生产助手：

- 顶部：新对话、历史、分享（新对话时禁用）、设置、CLI 与 Skill、关闭。
- 首页：推荐 Skill、刷新、通知提示。
- 输入框：支持 `@工作流 / 节点 / 资源`。
- 附件：本地上传、资产库。
- 模型选择：图片模型、视频模型。
- Skill：创建、全部、通用、收藏、我的，支持搜索、详情、添加和浏览全部。
- 生成模式：
  - 手动：每次生成前确认；
  - 自动：Agent 可连续执行生成。
- 设置：图片/视频自动生成、浏览器通知、提示音。自动生成会明确警告可能直接消耗积分。
- 空输入时发送不可用。

Agent 的价值不是独立聊天，而是把当前画布选择、节点关系、素材引用、模型与 Skill 纳入同一个可执行上下文。

## 11. 端到端功能联动

```text
上传 / 素材库 / 角色库 / 历史结果
                ↓
             画布节点
                ↓
      依赖连线 / Agent @引用
                ↓
       图片 / 视频 / 音频生成
                ↓
      历史沉淀 / 下载 / 再次复用
                ↓
      故事板汇总 / 智能编辑入口
                ↓
           发布或分享
```

关键状态机：

- 工具状态：选择 → 连接/移动/手型 → 完成或 Escape → 选择。
- 面板状态：关闭 → 打开单一资源面板 → 切换标签 → 关闭并恢复焦点。
- 生成状态：配置 → 确认 → 排队/执行 → 成功/失败/取消 → 历史与画布同步。
- 视图状态：工作流 ↔ 故事板；切换不丢项目状态和当前保存结果。
- Agent 状态：关闭 → 打开 → 选择上下文/模型/Skill → 手动确认或自动执行。

## 12. 现有本地画布的能力与差距

现有 `/project/:projectId` 已具备 React Flow 画布、结构化节点、依赖连线、生成队列、撤销重做、持久化、节点列表、AI Director、工作流执行、评论协作、预览/导出和时间线数据。主要差距是：

1. 缺少 Liblib 式全局工作台信息架构，平台级、资源级和画布级入口混在一起。
2. 工作流/故事板缺少同页切换。
3. 添加节点仍是平铺工具栏，复杂度增长后会挤占画布。
4. 资源、历史、快捷键、教程没有统一侧栏/弹窗容器。
5. Agent 以底部编辑器存在，未形成可收缩右侧工作面板。
6. 小地图、吸附、缩放等视图控制不完整。
7. 图片节点缺少统一的上下文创作工具入口。

## 13. 可借鉴与需优化之处

应保留：四周控制、中间创作；模式切换；节点上下文动作；资源—生成—复用闭环；Agent 与画布上下文绑定；高密度快捷键。

应优化：

- 工具点击先进入配置预览，再确认创建，避免误增节点。
- 顶栏只保留项目级动作，画布编辑动作归入创建工具坞和上下文栏。
- 同一时间只打开一个主要面板，所有弹层支持 Escape、焦点回归和键盘操作。
- 生成成本在确认前可见，自动模式提供明确的全局安全开关。
- 视图偏好本地持久化，但不进入项目撤销历史。
- 在小视口和 200% 缩放下，工具坞、Agent 与选中节点动作不得重叠。

## 14. 复刻优先级

第一轮应先实现能够贯穿现有功能的工作台骨架：顶栏模式切换、创建工具坞、左侧资源面板、右侧 Agent、小地图与视图控制、故事板汇总、图片上下文工具。更深的云素材、模型市场、积分、发布、多人协作和真实时间线作为后续服务端功能域接入。
