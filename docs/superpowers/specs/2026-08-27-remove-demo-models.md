# 移除用户可见演示模型

## 目标与边界

- 图片、视频、文本、脚本、音频及 Agent 模型菜单仅使用真实火山 Provider 和能力匹配的待接入项。
- 移除历史 Mock Studio 目录及通义图片、文本/音频演示档位；不删除用户已有节点、版本、资产或历史记录。
- 默认/旧模型 ID 必须回落至对应真实 Provider 的配置状态，禁止静默执行演示生成。线上无配置时生成按钮禁用且显示原因。
- 保留现有 12 个功能占位：原批次的 11 项及已被预设使用的设定图项，不扩展 AI 服务。
- 只留 `internal-demo` 作为显式寻址的开发测试执行器，`selectorVisible:false`，生产禁止生成；本地导出不依赖已删除模型。
- `menuCapabilities` 只声明待接入服务在哪类菜单展示，不扩充真实执行能力。图片菜单 1 个真实模型 + 6 个待接入项；视频/Skills 菜单 1 + 4；音频菜单 2 + 2；文本/脚本菜单 1 个真实模型。
- 保留原有前端编辑、素材、手动文本、结果预览与导出能力；线上整组执行不再偷偷运行模拟生成，也不会升级为付费批量调用。

## TDD 与验收

1. 注册表可见清单、隐藏项不得泄漏、四类默认生成不得回退 demo：先红（6 项已确认失败）。
2. 迁移节点默认值、旧项目引用、Agent 偏好以及批量执行；保留端口、参数、结果与持久化语义。
3. 测试改用注入 fixture/拦截真实 Provider 请求，不将旧演示模型重新暴露到产品目录。
4. 全量 typecheck、Vitest、build、Playwright；构建显式 mock 环境并清空密钥，测试禁止真实付费网络。
5. 只提交本任务变更；保留已有三个 design-qa-evidence 截图修改。

## 回归修复与验证范围

- 清理 Skills 页独立硬编码的模型列表，同时覆盖画布节点、Agent 两个选择器与旧项目的模型回落。
- 文本/脚本按钮补充模型配置资格校验，不能仅凭提示词非空就返回本地假结果。
- 浏览器 fixture 使用假 Key 与 `.invalid` API 域名，真实火山域名拦截；视频素材为独立生成的 5 秒纯色测试文件。
- 生成链路、队列、取消、历史与持久化测试显式注入 fixture；生产构建另用 HTTPS 静态 fixture 验证未配置禁用态以及零生成请求。
- 真实适配器的远程图片 fixture 暴露了裁切读取像素缺少 CORS 标志的问题：图片/视频像素处理加载器设置匿名 CORS，不绕过服务器权限限制。
- 故事板定位节点在画布恢复显示并完成两帧布局后适配视口，避免隐藏层尺寸导致 NaN；保留控制台零错误断言。
- 窄视口测试使用正常缩放控制露出完整高级参数；连接状态断言只检查连接引导已退出，不再把独立的生成完成提示误判为连接失败。
