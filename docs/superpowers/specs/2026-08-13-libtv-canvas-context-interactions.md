# Liblib 风格画布上下文交互规格

日期：2026-08-13
目标路由：`/project/:projectId`

## 1. 背景与目标

当前画布工作台已经具备节点、依赖连线、生成队列、项目持久化、故事板、预览与导出，但创建入口集中在固定底部工具坞，和 Liblib 画布以“画布即入口”的交互方式不一致。本阶段只重组创建与上下文入口，不复制 Liblib 品牌，也不替换已验证的数据与生成链路。

目标：

- 空白画布右键打开上下文菜单。
- 节点右键打开同一套上下文菜单，并提供可执行的“保存到我的资产”。
- 双击空白画布直接打开自由生成节点编辑器。
- 移除旧固定创建工具坞及其节点类型按钮。
- 把连线、分组、连线显隐和资源面板入口迁移到顶部模式工具栏。
- 所有创建继续写入现有项目 Store，保持撤销、重做、自动持久化与生成链路不变。

## 2. 非目标

- 不调用 Liblib 私有接口，不上传到云端，不消耗第三方积分。
- 不新增第二套节点模型、连接模型或项目持久化协议。
- 不改变预览、导出、生成队列和时间线的数据契约。
- 不实现操作系统级复制；本阶段粘贴仅读取浏览器允许访问的文本剪贴板。

## 3. 信息架构

```text
顶部项目栏
├── 工作流 / 故事板
├── 撤销 / 重做
└── 预览 / 导出 / Agent

工作流画布
├── 顶部模式工具栏
│   ├── 双击画布提示
│   ├── 连线 / 分组 / 连线显隐
│   └── 资产 / 历史 / 快捷键 / 帮助
├── 空白画布上下文菜单
│   ├── 上传
│   ├── 保存到我的资产（无可保存节点时禁用）
│   ├── 添加节点（二级节点类型）
│   ├── 撤销 / 重做
│   └── 粘贴（无剪贴内容时禁用）
└── 节点上下文菜单
    └── 保存到我的资产（节点有活动素材时启用）
```

## 4. 交互契约

### 4.1 空白画布右键

1. 阻止浏览器原生菜单。
2. 关闭已有节点/边选择中的边选择，但不破坏项目数据。
3. 菜单锚定在鼠标位置，并被限制在画布可见范围内。
4. 菜单打开后首个可用菜单项获得焦点。
5. `Escape` 关闭菜单并把焦点返回画布区域。
6. 点击菜单外部关闭菜单。

### 4.2 节点右键

1. 阻止浏览器原生菜单。
2. 右键节点成为主选择节点。
3. 若活动版本绑定图片或视频素材，“保存到我的资产”启用；否则禁用。
4. 保存成功后使用现有资产库记录格式写入本地资产库，并通过状态消息反馈。
5. `Escape` 关闭后焦点回到对应节点。

### 4.3 双击自由生成

1. 仅空白画布的第二次点击（`detail >= 2`）触发，不响应节点、按钮、连线或面板双击。
2. 使用鼠标位置通过 React Flow `screenToFlowPosition` 转为节点坐标。
3. 打开标题为“自由生成节点”的文本生成编辑器，默认名称沿用 `文本 01` 编号规则。
4. 取消不写项目历史；确认后创建一个文本节点、选中并聚焦，且可撤销、可持久化。

### 4.4 右键菜单动作

- 上传：在锚点打开图片上传编辑器；确认后仍走现有图片节点和资产创建链路。
- 添加节点：展开剧本卡、角色卡、世界观卡、文本、图片、分镜、视频；选择后在锚点打开对应编辑器。
- 撤销/重做：直接调用现有 Store；边界状态禁用。
- 粘贴：菜单打开时安全读取文本剪贴板；空白、拒绝权限或 API 不可用时禁用；有文本时在锚点创建文本节点。
- 保存到我的资产：把节点活动素材转换成现有 `LibraryAssetRecord` 并保存；无活动素材或仓储不支持写入时禁用。

## 5. 状态与焦点

上下文菜单状态属于瞬时 UI，不进入项目撤销历史：

```ts
interface CanvasContextMenuState {
  projectId: string
  anchor: { x: number; y: number }
  bounds: { width: number; height: number }
  flowPosition: { x: number; y: number }
  targetNodeId?: string
  clipboardText: string
  returnFocusTo?: HTMLElement
}
```

- 项目切换、故事板切换、开始连线、打开节点编辑器时关闭菜单。
- 菜单关闭和编辑器取消后恢复到仍连接在 DOM 中的触发目标；否则回退到画布区域。
- 资产保存和粘贴失败不得破坏项目；使用 `role=status` 反馈结果。

## 6. 响应式与视觉

- 上下文菜单宽约 240px，深色浮层、12px 圆角、细边框和轻阴影。
- 顶部模式工具栏不再包含任何节点创建按钮。
- 721×778 和 200% 布局下，菜单完整矩形应位于可见画布内；二级节点菜单允许内部滚动。
- 右侧 Agent 打开时，菜单按实际画布区域夹取，不进入 Agent 覆盖区。

## 7. TDD 顺序

1. 组件 RED：上下文菜单项、禁用状态、Escape 与焦点回归。
2. 页面 RED：空白右键、节点右键、双击自由生成、上传/添加节点、粘贴与资产保存。
3. 页面 RED：旧“创作工具”不存在；顶部“画布模式工具”保留连线、分组、连线显隐和资源入口。
4. GREEN：实现菜单组件、页面状态和事件接线。
5. GREEN：重组工具栏、删除旧创建按钮和放置工具模式。
6. 回归：节点拖动/连接、生成队列、自动保存、故事板、预览与导出相关测试。

## 8. 验收标准

1. 空白画布右键能看到六个指定主菜单项。
2. 无剪贴内容时“粘贴”明确禁用。
3. 节点右键后“保存到我的资产”可用并写入本地资产仓储。
4. Escape 关闭菜单并正确回焦。
5. 双击空白画布打开“自由生成节点”，确认后只产生一次项目历史。
6. 页面不再渲染旧“创作工具”工具坞，也没有常驻节点类型创建按钮。
7. 顶部模式工具栏保留连线、分组、显隐、资产、历史、快捷键和帮助。
8. 既有节点模型、依赖、生成、持久化、预览和导出回归通过。
9. 全量 Vitest、TypeScript 类型检查和生产构建通过。
