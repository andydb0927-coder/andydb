## 0. 判定口径

| 状态 | 含义 |
|---|---|
| A 已实现 | 用户操作会产生与功能名称一致、可复验的真实状态变化；IndexedDB、本地文件处理等仅本机能力也算 A，但会明确边界。 |
| B 有 UI 无实际功能 | 有按钮、面板或演示反馈，但使用静态数据、固定结果、临时状态，或没有业务处理器。 |
| C 半实现 | 功能只完成一部分，或只有部分 Provider/环境能形成闭环。 |
| D 没有 | 没有入口/数据模型/处理器，或入口明确禁用。 |

“是否需要真实 API”按以下方式记录：

- **否**：可由当前前端、浏览器媒体能力或本地 Repository 完成。
- **部分（待请示）**：界面与本地数据可先实现，但 AI 推理、媒体处理、云同步或生产交付仍需外部服务。
- **是（待请示）**：要达到指南语义必须接真实模型/服务；不得把 Demo Provider 当作已接入。
- Seedream 图片与 Kling 视频虽已有条件启用的开发直连，但仍是前端开发验证链路；生产密钥代理、配额、任务追踪等继续按“待请示”处理。
