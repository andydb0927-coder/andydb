范围：当前仓库可达路由、画布工作台、节点详情、弹窗/抽屉/菜单，以及源码中已有但没有运行时入口的组件。

## 1. 状态口径

| 状态 | 判定标准 |
|---|---|
| A 已实现可真实用 | 用户操作会产生与功能名称一致、可复验的状态变化；浏览器本地持久化也算真实可用，但必须注明数据来源和“仅本机”边界。 |
| B 有 UI 但假数据或死按钮 | 界面存在，但内容来自硬编码演示数据、操作只显示提示、只改临时组件状态，或按钮没有业务处理器。 |
| C 半实现 | 同一功能中只有部分链路闭环，或仅在特定环境/Provider 配置下真实可用，其余仍为演示、临时态或占位。 |
| D 纯占位 | 明确禁用、只有说明文字、没有路由/入口/处理器，或组件存在但运行时不可达。 |

### 1.1 主要数据来源

- **浏览器 IndexedDB**：项目、节点、连线、时间线、生成任务/项目资产、资产库、评论、发布作品、社区本地状态等。该类数据可刷新保留，但默认不跨浏览器、设备或域名。
- **浏览器 localStorage**：平台阶段任务、Agent 偏好、故事板折叠状态、账号菜单偏好等。
- **静态常量/组件内状态**：首页内容、挑战赛、教程、风格、特效、角色、部分推荐内容；关闭组件或刷新后不一定保留。
- **Provider Registry**：`demo` 返回本地演示结果；`placeholder` 明确不可调用；`live` 只有在开发直连模式与环境变量完整时才真实请求。当前真实链路包括条件启用的 Seedream 图片和 Kling 视频。
- **LibTV CLI 开发桥**：仅在本机桥服务、CLI 登录和写入开关均就绪时可用；不能视为默认生产能力。

## 6. 关键结论

1. **本地画布编辑已经是产品中最完整的部分。** 项目、节点、连线、布局、撤销、故事板、时间线、评论、JSON 导入导出均有实际数据闭环，可归为 A。
2. **“生成”必须按 Provider 分开判断。** 队列和 UI 是真的；Demo 模型结果是假的；Placeholder 不可调用；Seedream/Kling Live 只有开发直连配置完整时才调用真实 API，而且结果当前为内存临时态。
3. **平台内容型页面多数是可交互的演示站。** 挑战赛、教程、推荐、角色、风格、素材主要使用静态常量；不能因筛选按钮能点就判为真实线上功能。
4. **视频后处理和 Agent 是最大的“看起来完整、实质未闭环”区域。** 大量按钮只开面板、改临时状态或显示反馈。
5. **发布、分享与社区仅在当前浏览器成立。** 本地发布可用，但没有服务端，复制出的链接不能让另一台设备或另一个浏览器读取同一作品。
6. **资产管理存在数据一致性缺口。** 上传图片与项目资产可持久化，但面板内重命名/移动/删除仍是临时态；“保存到我的资产”也是反馈占位。
7. **账号、积分会员、团队、支付仍未进入真实产品阶段。** 目前不存在对应路由和服务层。

## 7. 激活优先级建议

### P0：高频刚需

| 优先项 | 当前问题 | 激活完成标准 |
|---|---|---|
| 生产级生成代理与统一结果持久化 | Live 依赖前端开发直连，结果只在内存；Demo/Live 体验割裂 | API Key 只在服务端；任务可查询/取消/重试；Live 结果统一写入节点版本、资产和历史；刷新后仍在。 |
| 资产管理真正持久化 | 重命名/移动/删除和“保存到我的资产”是假操作 | 全部操作调用同一 Asset Repository；刷新、重开面板后一致；节点引用删除有影响确认。 |
| 图片/视频/音频完整上传 | 目前只支持图片 | 支持图片、视频、音频类型校验、预览、失败提示、资产入库和发送画布。 |
| 视频参考与生成控制闭环 | 参考/标记/特效/主体/角色/运镜大多不进入请求 | 每个入口产生结构化参数或真实连线，并由 Provider 能力校验、请求映射和结果回填覆盖。 |
| 音频节点生成与播放 | 只有参数，没有生成核心 | 提示词、Provider、成本、队列、结果、播放器、下载、历史完整闭环。 |
| 云端发布与可分享查看 | `/view/:id` 只在同浏览器有效 | 作品快照上传服务端；分享链接无本地数据库也可访问；包含权限、删除/下架和错误页。 |
| 清理高频死按钮 | 图像标注、九宫格、视频处理等入口容易误导 | 要么实现真实结果，要么明确标“暂未开放”并从主路径降级；禁止用“操作完成”假反馈。 |
