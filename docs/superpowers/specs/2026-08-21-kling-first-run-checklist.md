# 可灵首次真实生成验证清单

日期：2026-08-21  
状态：准备就绪，等待临时开发密钥  
适用范围：仅限本机 `localhost` 开发验证

## 1. 目标与安全边界

本清单只验证以下最小闭环：

> 点击生成 → 调用可灵官方 API → 轮询任务 → 取得结果 URL → 当前视频节点直接显示。

本轮不接对象存储、后端数据库或服务端任务队列；结果只保存在当前页面的内存态中，不写入生成历史、资产库、项目快照或版本记录。刷新页面后临时结果失效。

安全边界：

- 只在本机开发服务器验证，不得用于公开 Preview、Vercel、Netlify 或生产环境；
- 只使用低额度、可随时撤销的临时开发凭证；
- 不在文档、截图、终端输出、Issue、聊天记录或 Git 中保存真实密钥；
- 不保存包含 `Authorization` 请求头的 HAR 或完整网络日志；
- 首次验证只使用单供应商、单模型、文生视频、单结果；
- 未提供密钥前不得创建真实请求，配置不完整时不得静默回退 Mock。

## 2. 已核对的实现契约

实现读取 4 项环境变量，其中 1 项是运行模式，3 项是可灵配置：

| 变量 | 用途 | 必填条件 |
| --- | --- | --- |
| `VITE_GENERATION_MODE` | 生成模式 | 必须等于 `kling-direct-dev` |
| `VITE_KLING_API_KEY` | 临时开发 API Key | 开发直连必填 |
| `VITE_KLING_API_BASE` | 官方 API 基地址 | 开发直连必填，实施当天复核 |
| `VITE_KLING_MODEL_ID` | 已开通的单模型 ID | 开发直连必填，实施当天复核 |

配置门行为：

- 注册表始终注册 `kling-api`，类型为 `live`；
- 只有模式为 `kling-direct-dev` 且 3 项可灵配置全部存在时，Provider 才可用；
- 缺少任意一项时，模型选项和生成入口保持禁用，并显示“可灵开发验证配置未完成”；
- 缺配置时不得发送请求，也不得改用 Mock 冒充真实生成；
- 默认 `mock` 模式与现有本地演示行为保持不变。

## 3. 密钥到位后的配置模板

密钥到位后，在 `app/.env.local` 中人工填写以下模板。不要把真实值粘贴到本文档或提交记录：

```dotenv
VITE_GENERATION_MODE=kling-direct-dev
VITE_KLING_API_KEY=<临时开发 API Key>
VITE_KLING_API_BASE=<实施当天确认的官方 API 基地址>
VITE_KLING_MODEL_ID=kling-2.6
```

注意：`VITE_*` 会被 Vite 注入浏览器代码，不具备保密能力。本配置仅用于本机短期协议验证；生产必须改用服务端代理。

## 4. 启动前检查

- [ ] 确认使用的是临时、低额度、可立即撤销的开发 Key；
- [ ] 确认官方控制台已开通目标文生视频模型；
- [ ] 确认 API 基地址和模型 ID 来自实施当天的官方信息；
- [ ] 确认 `app/.env.local` 已被 Git 忽略：

  ```bash
  git check-ignore -v app/.env.local
  ```

- [ ] 确认环境文件未被跟踪：

  ```bash
  git status --short -- app/.env.local
  ```

  正常结果应为空；如果出现已跟踪记录，立即停止验证并先移除跟踪状态。

- [ ] 关闭会自动上传控制台日志、网络日志或工作区文件的第三方工具；
- [ ] 确认浏览器只打开本机地址，不通过公网隧道或局域网共享；
- [ ] 确认当前没有仍在轮询的旧 live 请求。

## 5. 首次验证步骤

### 5.1 启动开发服务器

1. 在 `app/.env.local` 填入临时配置；
2. 停止旧开发服务器。Vite 只在启动时读取环境变量，修改配置后必须重启；
3. 从仓库根目录启动：

   ```bash
   npm --prefix app run dev -- --host 127.0.0.1 --port 4173
   ```

4. 只打开 `http://127.0.0.1:4173/`；
5. 打开浏览器开发者工具，只观察状态码、请求时序和脱敏后的响应结构，不复制授权头或完整防盗链 URL。

### 5.2 进入画布并提交一次生成

1. 从首页新建项目，或打开一个本地测试项目；
2. 创建或选中一个空的视频节点；
3. 在模型选择器中选择 `Kling` live 模型；
4. 确认该选项显示为“开发直连”，且“可灵开发验证配置未完成”提示已消失；
5. 确认节点没有参考素材。本轮只验证文生视频，带参考素材应被拒绝；
6. 输入一条不含人物隐私、品牌、版权角色或敏感内容的短提示词。建议首测：

   > 清晨薄雾中的空旷石桥，摄影机缓慢向前推进，无人物、无文字、无品牌标识。

7. 保持默认参数，确认界面可见预计成本；
8. 只点击一次“生成”，不要连续点击或并发提交；
9. 依次观察界面状态：`已提交` → `生成中` → `结果直显`；
10. 确认最终结果 URL 在当前视频节点播放器中直接显示，且标记为临时结果；
11. 记录观测数据后刷新页面，确认临时 live 结果不会从项目持久化、生成历史或资产库恢复。

### 5.3 必须立即停止的情况

出现以下任一情况时停止，不盲目重试：

- `401` 或 `403`：密钥、签名、权限或模型授权异常；
- `429`：额度或频率限制，记录 `Retry-After` 后停止；
- `5xx`、轮询超时或状态长时间不变化；
- 返回字段与 fixture 契约不一致；
- 结果 URL 不是 HTTPS、不可播放，或来源与本次任务不一致；
- 出现未预期的重复提交、持续轮询或费用增加；
- 控制台、网络日志或错误提示暴露完整密钥、签名或授权头；
- 配置缺失时仍发生网络请求或自动回退 Mock。

## 7. 成功判定

首次验证只有同时满足以下条件才算通过：

- [ ] 只产生 1 次创建任务请求；
- [ ] 状态按“已提交 → 生成中 → 结果直显”推进；
- [ ] 结果来自本次任务，且在当前视频节点播放器中显示；
- [ ] 预计成本可见，官方实际扣量已记录且符合预期；
- [ ] 没有把结果写入项目、生成历史、资产库或版本记录；
- [ ] 刷新后内存态结果消失；
- [ ] 错误路径没有静默回退 Mock；
- [ ] 控制台与记录中没有泄漏密钥或授权信息。

## 8. 回退与密钥撤销

1. 停止开发服务器，终止尚未完成的本地轮询；
2. 将模式改回：

   ```dotenv
   VITE_GENERATION_MODE=mock
   ```

   或直接删除本机 `app/.env.local`；
3. 重启开发服务器，确认本地演示 Provider 恢复默认行为；
4. 确认 `Kling` live 模型重新禁用，并显示“可灵开发验证配置未完成”；
5. 在可灵官方控制台立即撤销或轮换本次临时 Key；
6. 删除任何包含授权头、签名或完整结果 URL 的临时网络导出和本地日志；
7. 再次运行：

   ```bash
   git status --short
   git check-ignore -v app/.env.local
   ```

8. 确认环境文件没有进入 Git，工作树只保留预期的代码或文档改动。
