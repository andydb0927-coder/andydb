# 主体库与角色一致性增强

起点 `925f924fa4a875a5411ebf193418028cd55e0e8b`；保留3张既有在途截图。只用本地 fixture，不触发真实计费。

## 契约

1. 主体详情支持画布内查看及 `/subjects/:subjectId` 独立页：描述、样本/来源图、源项目、当前引用项目、角色/分镜引用数、生成任务使用次数。统计来源为 IndexedDB 项目与当前未保存项目覆盖，不把切画布快照重复计数。
2. 主体可选保存原图尺寸；旧记录无尺寸仍可读。编辑描述不覆盖历史任务。新生成提交前读取主体最新资料，将描述与参考图写入请求快照；真正调用时前置一致性指令，原始提示词保持不变。历史重发/重试使用原快照。
3. 角色库“使用”在已有选中图片/视频目标时创建主体参考节点并连接，否则保留原来独立插入方式。从连线及脚本分镜角色绑定收集主体，不自动引用无关角色。
4. 相似提示：本地描述/标签词重叠（中文双字片段、英文单词）85% + 图片宽高比接近度15%；缺尺寸只计算文本，同源图直接提示。阈值 >0.72。不是人脸识别/身份判断。合并须明确选择：保留已有ID/引用、补充样本/描述/标签；也可仍新建或取消，取消不写数据、不重新调用AI。
5. 删除前显示引用影响。删除只移除主体库记录，已生成图片、角色参考快照和历史任务保留；不删除其他项目/分镜/资产。库读取或统计失败时禁止宣称无引用。
6. 新字段可选；工作流JSON携带并校验主体快照。持久化不升级/清空已有数据结构。
