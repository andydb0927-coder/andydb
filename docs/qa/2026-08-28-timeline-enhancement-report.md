## 已实现

| 功能 | 入口与行为 | 持久化与回归 |
| --- | --- | --- |
| 转场 | 选择非首个图片/视频片段 → 入场转场 → 淡入淡出、交叉溶解、黑场及秒数 | `transitionIn`；同轨连续片段有效，时长按相邻短片段限制；播放与合成共用帧规划 |
| 字幕轨 | 在播放头添加字幕 → 编辑文本、起止时间、字号、颜色、背景、位置和粗体 | 独立字幕片段及 `subtitleStyle`；预览显示，WebM 逐帧烧录；支持换行 |
| 多轨音频 | 新增音频轨道 → 添加/移动音频片段 → 设置起点与音量关键帧 | 独立 `trackId`、锁定起点、`volumeKeyframes`；统一时间刻度；所有活跃音轨同步播放并混流 |
| 进度与取消 | 导出合成视频 → 准备素材 / 合成 / 封装 → 下载；处理中可取消 | 禁止重复启动；取消、错误、切项目或卸载均清理媒体资源，不下载半成品 |
| 保存恢复 | 自动保存、刷新恢复；写入失败显示重试入口 | IndexedDB 原 schemaVersion=1 不变；可选字段兼容旧时间线；JSON 保留完整参数 |

同时补齐变速/截取/分割后的音量包络重映射，避免关键帧与声音错位；修复保存失败未反馈的问题，保留未保存快照供重试。同轨重叠片段按空闲子行排布，不修改时间位置，也不因简单计算重叠数量而互相遮挡。

截图复核发现新增转场标签会超出原固定高度轨道；已先添加失败 E2E，再将轨道高度改为根据卡片实际内容测量。未隐藏标签或按钮，未修改时间坐标。

## 决策与限制

1. 采用 canvas + WebCodecs + OfflineAudioContext，固定 `mediabunny@1.55.3` 用于本地 WebM 封装及编码背压处理，按需加载，不向该依赖或服务器发送媒体。未伪称 MP4 或云端合成，纯本地无积分费用。
2. 首轮实时录制实现曾全量通过，但复验发现并发负载下视频帧只覆盖约2.17秒、音轨接近4秒的真实漏帧问题。已改为逐帧时间戳编码，等待编码和封装完整完成，补尾段像素断言及并发重复导出。两路并发的3次重复均通过（约2.2–6.5秒/次）；五路同时编码超过60秒测试时限，性能边界如实记录，不视为已支持的吞吐量。补充编码背压等待中可取消的回归；长片/低性能设备内存未作专项基准测试。
3. 转场不移动剪辑点、不缩短总长。交叉溶解从前片段末帧过渡到后片段；淡入淡出在切点两侧分配时长，黑场增加短暂停黑。
4. 仅混合显式音频轨；视频原声需先提取至音轨，避免重复叠音。字幕和音频可独立于画面存在。
5. 跨域素材需允许读取或先导入本地。失效地址、素材实际时长短于出点、浏览器不支持编码时明确阻止导出，不跳过素材伪造成功。
6. JSON 保存完整增强参数，EDL 保持原基础剪辑决策格式；原手动预览录制入口保留，仅录画面。

## 操作卡

1. 画布“发布与分享” → 预览，进入“成片预览”的多轨时间线。
2. 添加图片/视频片段，选择第二个连续片段，设置“入场转场”和时长。
3. 在播放头添加字幕，选中字幕修改时间与样式。
4. 新增音频轨道，把音频放到对应轨，设置“音频开始（秒）”和音量关键帧。
5. 预览确认后点击“导出合成视频”；等待下载，或点击“取消导出”。
