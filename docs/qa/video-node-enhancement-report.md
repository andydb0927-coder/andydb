## 官方依据与边界

详细规格：[视频节点增强规格](../superpowers/specs/2026-08-28-video-node-enhancement.md)。官方来源：[创建任务](https://www.volcengine.com/docs/82379/1520757)、[查询任务](https://www.volcengine.com/docs/82379/1521309)。

- `content[].image_url` + `role:first_frame/last_frame` 为官方首尾帧格式；该场景不混入额外图、视频或音频。主体描述仍加入提示词，但不强塞主体图破坏首尾帧场景。
- 视频参考限制、真人授权、生成效果及真实时延仍由官方服务决定；本批通过的是 fixture 合同与本地编码验收，不等于真实供应商生成验收。
- 本地合成为**无音轨 WebM**，不宣称 MP4 或音频混音。副视频短于主片时循环，旋转/镜像作用于主片，三分屏按比例留黑边。输出规格中的 30 fps 是采集目标，实际帧调度受浏览器影响；录制时长可能有帧级偏差。
- 本地媒体必须能被浏览器解码；跨域素材需允许 CORS。读取、编解码失败及 20 秒加载超时都显示错误，不写入不完整结果。

## 操作卡

1. 视频节点选择已配置的“火山方舟 · Seedance”→生成模式选“图生视频”或“首尾帧”→从项目图片选择首帧/尾帧。在高级设置填写景别、镜头运动及负面词，再走现有成本确认与生成流程。
2. 成功结果播放器上显示信息卡。至少有两版时，展开“视频版本”→选择旧版本；恢复不消耗积分，可撤销，并自动保存。
3. 选中有结果的视频→媒体工具条“剪辑”→“镜像 / 旋转 / 变速 / 合成”。等待真实元数据读取，设置选区/变换/布局；画中画选1个副视频，三分屏选2个→“导出处理视频”。输出新视频节点和资产；关闭或切换画布取消处理。
4. 旧“剪辑”“裁剪”入口继续可用，读取失败会显示原因，不产生假完成反馈。
