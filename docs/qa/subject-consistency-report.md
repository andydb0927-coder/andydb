## 使用与边界

1. 角色库 → 本地主体卡“详情” → 编辑特征描述 → 保存。
2. 选中图片/视频节点 → 角色库“使用” → 自动创建参考连线 → 输入场景提示词 → 按现有费用确认生成。
3. 重复提取时核对相似提示，选择“合并到…”、“仍新建主体”或取消；删除时先核对引用项目和分镜影响。

本批验证接线和持久化，不声称fixture图片证明真实模型的人物一致性效果。相似提示是本地启发式，不是人脸识别；主体库仅在同一浏览器中跨项目复用，外部来源URL仍受原服务有效期约束。

回滚采用本批提交的 `git revert`；新字段可选，旧版本可忽略，无需清空IndexedDB。提交范围不包含原有3张在途截图，也不更新其他批次证据。
