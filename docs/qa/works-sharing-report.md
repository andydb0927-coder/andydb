## 关键决策与限制

1. `visibility` 与已有 `status`（发布/下架）分离；旧数据默认私密，无 IndexedDB 版本升级，不改既有记录结构的必填字段。
2. “公开”只代表本地标记，不上传云端、不实现访问控制；同一浏览器仍可打开自己的私密作品。分享链接没有跨浏览器云端数据。
3. 个人作品集不把首页固定示例算作个人创作。统计使用发布时冻结的 `jobs`，按项目与任务 ID 去重；模型次数是成功任务数，不是图片张数。积分优先 `creditsSpent`，成功任务缺失时使用 `estimatedCost`，未记录金额单列。不是供应商账单，也不包含发布后新增任务。
4. PNG 的二维码位不是可扫描码。封面过期、CORS 或编码失败必须反馈错误，不产生空白成功文件。导出中禁止重复提交，离开详情页后不触发滞后下载。
5. JSON 复用 `createWorkflowSnapshot`，旧导入器可识别；已存内联数据保留，外部素材仅含 URL/ID，不是媒体二进制归档，失效链接不能靠 JSON 恢复。
6. 不改生成 Provider、参数模型、任务队列或密钥文件；构建使用 `build:mock`，无新增运行依赖。
