## 使用方法

1. 添加并选中「导演台」节点，滚动到「3D 导演视口」。
2. 在「灯光布置」选预设；拖动视口光标，或选中灯光填写 XYZ。
3. 切换机位、焦距；从本地 3D 资产区拖入桌椅等道具。
4. 展开「运镜轨迹预览」，在不同机位记录至少两个位置，调整时长后播放。停止/播完恢复机位，数据刷新可恢复。
5. 「导出场景快照 PNG 到画布」或原「导出四视图 PNG 到画布」，结果进入图片节点和资产管理。

边界：这是本地场景布光与机位预览，不是视频生成；AI 运镜生成保持明确待接入。WebGL 不可用时可编辑保存场景数据，但播放与截图不可用且说明原因。
