## 明确边界与决策

1. 「提交生成」按本批按钮要求保留名称，含义是提交已有结果进入审核，旁边明确不发起 API；不虚构自动生成、AI 审核或客户签收。
2. 工作台使用独立本地数据库，不迁移原画布库；云端同步、真实文件交付、原片授权核验不在本批。
3. 原片引用允许外部素材编号，属于人工登记，不宣称已自动验证原文件。外部结果 URL 过期会明确显示预览不可用，保留资产标识。
4. 返修计数对应正式返修请求，资料编辑或 Provider 重试不计为客户返修。
5. QA 等级使用批 1 模板建议；勾选为人工确认符合或不适用。真实检测器及客户最终验收口径仍需后续对接。
6. 回滚仅撤销本批代码，保留独立数据库资料；原画布结构不变。测试前已备份既有截图，测试后恢复；起始三个无关截图不纳入本批提交。
