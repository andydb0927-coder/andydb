# 出海转绘批4 · 交付导出与版本台账验收

## 范围与决策

- 起点 `5012abc`；分支 `codex/platform-shell-phase`。基线：215文件1724项单测、149项E2E。
- 客户PDF第12–17页已提取正文并渲染审阅，复核交付、字幕、声音、海报和飞书规范；交付契约详见[规格文档](../superpowers/specs/2026-09-10-dubbing-delivery-contract.md)。
- 本批交付包是**清单JSON快照**：包含自审全文、版本/资产/报告/文件引用，不是二进制视频ZIP，不转码、不自动上传、不承诺客户签收。
- 自审原规则允许WARN进入人工确认；交付所有11个自动子项必须PASS。口型0.3–0.5s和缺数据均阻塞，不修改旧runner语义。
- 客户要求尚未自动探测的SDR/分轨声音/字幕外观/海报等以外部报告引用+人工逐组核验留接口，明确不验证报告真伪、不伪装为自动检测。
- 集名从当前工作台实际数据计算，结合全剧预期集数；镜头范围不代表全集完整性。修改台账复用revisionCount/revisions，满3禁止返修，中文指引人工复核。
- 独立dubbing命名空间新增可选字段，旧数据不清空、不迁移画布主模型；已通过的旧记录必须补足交付证据，过期确认走返修/人工复核，不能绕过门禁。

## TDD与回归记录

1. 新交付域测试先因缺模块失败；实现后校验：自动项完整、原始人工WARN保留、范围/连续性、缺数据/失败/口型警告、过期自审、外部证据缺失、空/重复核验项、不可变快照。
2. 仓储测试涵盖旧deliver无法绕过、同版本并发仅一次成功、整集任一失败不部分写入、多镜全过事务提交、刷新恢复。
3. UI测试先因面板未实现失败；实现后测试阻塞原因、整集参数传递和保存失败中文提示。
4. 首次专项E2E发现交付入口打开时被禁用导致Esc无法回焦；增加失败单测后保持入口在弹层期间可聚焦，使用现有对话框焦点机制修复。失败日志保留，不增加重试。
5. 全量门禁首次类型检查发现新增Testing Library测试误用Playwright的exact参数；移除不适用参数后从第一道门禁重跑，保留失败日志。

## 使用与回滚

工作台右上“交付包检查与导出”→选择镜头/整集→修正全部红色阻塞项→逐镜登记已检测的报告与文件引用→填交付引用→生成清单并记录交付→展开台账下载JSON。重开页面可下载原清单。

代码可整批revert，新增可选数据字段保留；不使用reset、清库或删除旧版本回滚。旧代码缺交付门禁，不可在回滚后继续无检查交付已启用新流程的数据。三环境能力与不承诺项见[工作台README](../../app/src/features/dubbing/README.md)。
