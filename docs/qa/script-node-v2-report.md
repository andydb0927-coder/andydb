旧脚本生成、原模型菜单、其他节点与队列行为保留；没有改数据库表结构、真实供应商传输协议或用户本地环境变量。新增工具 provider 为隐藏条目，不增加用户模型选择器条目。

## 操作卡

1. 添加“脚本”节点，点“AI拆解”打开“脚本 v2 工作台”，输入剧本原文。
2. 再点工作台“AI拆解”，核对费用并确认；检查章节、场景、角色与道具。
3. 点“生成分镜故事板”，确认后编辑镜头参数与参考角色。
4. 选择起止镜头、比例与清晰度，核对实际尺寸及总费用，点“批量生成分镜”并确认。
5. 失败时查看单镜原因并重试；成功镜头自动跳过。可以随时“停止本轮任务”。
6. 角色选择参考图后点“提取主体”；各分镜点“发送画布”。关闭工作台后也可在顶部“故事板”继续编辑/发送。

费用来自现有 provider manifest：当前分镜图像估算 18 积分/镜，两镜确认 36 积分；拆解/分镜生成/主体提取沿用豆包声明，账单按实际 token 计费。产品积分估算不是人民币报价。本批没有发生任何真实生成费用。

## 边界与防护

- 复用现有 `seedream-direct-dev` / `ark-text-dev` 配置门；线上 mock 构建中未配置按钮禁用并显示原因，没有静默演示兜底。
- 角色视觉提取必须有样本图；文字设定不能冒充视觉识别。没有图时先上传/生成分镜，入口显示原因。
- 单次最多 12000 字原文、20 章节/40 场景、20 角色、30 道具、40 分镜；超过限制或引用不匹配会报错保留原数据。
- 刷新不能续接浏览器已断开的 HTTP 请求；中断任务只标取消，重试须用户再次确认。取消不能撤销服务端已经发生的费用。
- 结果沿用现有 URL 资产持久化策略；本批不新增云存储，也不承诺第三方临时 URL 永久有效。
- 工作流 JSON 不包含主体库/任务库迁移，导入时解除这些本地 ID；图片样本、分镜字段与画布关联按新 ID 保留。
