| 参数传输 | 语速/音量保持既有换算；音调 -12～12，TTS 写入 `additions` JSON 字符串的 `post_process.pitch`，音频生成写入 `audio_config.pitch_rate`；切模型恢复 manifest 默认值 |

| 安全边界 | 重复点击防重、AbortSignal、切项目/画布或来源变化时丢弃未提交结果；失败中文提示可重试；不会悄悄回退演示生成 |

## TDD 与实测

新增测试覆盖音色 ID、旧别名、请求体、音调边界、格式联动、WAV 文件头、增益包络、静音、非法区间、取消、防重、错误安全化、不可变参数快照、版本波形按需解码及失败提示、版本恢复与 IndexedDB 重开。

浏览器新增 2 条 fixture 用例：

1. **721×778**：生成两版 TTS → 试听不增加请求 → 恢复旧版本 → 刷新后音色/音调/提示词/音频一致。
2. **1440×1024**：音频生成 → 4 秒原音频以 2 倍速、0.2 秒淡入/淡出及归一化处理 → 实际解码输出 2 秒 WAV，峰值约 -1 dBFS，首尾接近零 → 导出入库 → 刷新仍可播放和下载。

过程中采样断言发现“原始峰值被淡出消除后，归一化不足”的问题，先新增失败单测，再改为按包络后的信号测量峰值；保留声道相对音量。首次 E2E 创建节点后、生成媒体使节点尺寸变化后，均使用产品“适配画布”再进行实际鼠标操作，没有强制点击或绕过遮挡。

全量回归曾捕获创意卡片用例的边缘点击超时：trace 中“编辑卡片”点击结束，但“编辑角色卡”未出现；独立诊断运行可通过。用例在空白区边缘创建卡片后缺少完整视口定位步骤，本批复用该用例原有的 `fitCreatedCardsIntoView`（适配、等待变换稳定、检查完整边界）再点击三种新卡片；没有改动创意卡片产品逻辑、增加重试或放宽编辑/连线/刷新断言。定位修正后针对性用例通过，最终状态以以下完整门禁为准。

本地音频结果遵循既有独立资产契约，不新增不受支持的 audio→audio 生成依赖。信息卡沿用本地任务积分账本：例如目标 12 秒的任务记 12 积分，fixture 返回原始计费时长 4 秒时，人民币估算按该返回值另列约 ¥0.066667；这不是实际账单。本批真实 API 调用及费用均为 0。

## 用户操作卡

1. 添加音频节点，选择已配置的豆包语音合成或豆包音频生成。
2. 选择官方音色，输入文本，调整语速、音量、音调及格式；确认成本后生成。线上 mock 构建仍保持真实 provider 未配置禁用。
3. 已有对应音色成功结果后，展开“音色样音”免费试听。首次没有样音会显示原因，不会自动扣费生成。
4. 在结果下方调整入出点、倍速、淡入淡出与归一化；“试听选区”只预览，“截取并导出 WAV”才新增资产与节点。
5. 同节点生成多版后展开“音频版本”，试听比较并恢复需要的版本；恢复不调用 API。

## 边界与回滚

- 支持范围为当前核实的 4 个官方音色，不等于全量供应商音色目录。音色克隆等原占位不变。
- 裸 PCM 仍支持下载，但不承诺浏览器原生播放；解码失败明确提示转换 WAV。建议验证使用 WAV/MP3。
- 浏览器本地解码可能采用设备采样率；导出 WAV 记录实际渲染采样率。变速会同时改变音高，不宣称具备保调变速。
- 本批新增字段均为可选，兼容旧节点、旧项目、旧中文音色值。不需要数据库清空或破坏式迁移。
- 回滚可逆向本批提交；保留已写入的可选字段与用户资产即可，不需要删除 IndexedDB。
- 三张任务开始前已修改的 QA 截图原样保留，不纳入本批提交。测试覆写的旧证据恢复到开始时版本，只新增本批证据。
